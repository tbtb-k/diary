M365 CopilotでClaudeを選ぶと、
今までできなかったことができるのか

調査日2026-09-28
調査対象M365 Copilotのモデル選択（Claude Opus など）
用途社内勉強会の最新機能紹介

モデル選択でClaudeに切り替えても、Copilotに新しい「機能」や「操作」が増えるわけではありません。変わるのは仕上がりの質と得意分野です。一方で、Claudeが加わったことで初めて成り立った新機能はあります。

モデルは「中で文章を考えている頭脳」のことです。Claudeを選ぶと頭脳が入れ替わりますが、メール・会議・ファイルを参照する仕組みや、Word・Excel・PowerPointを直接編集する機能は同じものを使います。「Claudeにしたら○○ボタンが出る」「Claudeにしたら△△にアクセスできる」といった変化は、公式情報では確認できませんでした。

ただし、長い資料の読み込みや何段階もある分析・資料作成では、Microsoft自身が「Claudeが強い」と説明しており、今まで実用レベルに届かなかった作業が届くようになることはあります。さらに、GPTが書いたものをClaudeが査読する「Critique」、同じ質問をGPTとClaudeに同時に投げて比べる「Model Council」、Claude Coworkの技術を取り込んだ「Copilot Cowork」は、Claudeが入ったからこそ生まれた「今までなかったこと」と言えます。

仕組みを一枚で How it works

勉強会では「頭脳」と「手足」に分けて説明すると伝わりやすいです。

頭脳 ＝ モデル 選べる部分

問いを理解して、文章・分析・構成を考える部分。ここを入れ替えるのがモデル選択です。

Auto（既定）GPT系Claude系

手足 ＝ Copilotの機能 共通の部分

社内のメール・会議・ファイルを探す、アプリを操作する、権限やセキュリティを守る部分。どのモデルを選んでも同じです。

Work IQ（社内データ参照）Word／Excel／PPTの編集権限・監査

＋ 頭脳を2つ組み合わせると ↓

複数の頭脳の組み合わせ ここが本当の新機能

1つのモデルでは原理的にできない「別会社のAI同士でのダブルチェック」や「同じ質問の出し比べ」が、Researcher（調査エージェント）の機能として用意されました。

Critique：GPTが下書き → Claudeが査読Model Council：GPTとClaudeの並列比較

問いへの答え
Claudeを選ぶと、新しい機能・操作が増える ✕ 記載なし 公式は一貫して「作業に合った頭脳を選べる」という説明。社内データの参照やアプリ操作はモデルと関係なくCopilot側の仕組みです。 [2][4][7]
Claudeを選ぶと、難しい仕事の仕上がりが良くなる △ 作業次第 Microsoftは「文書・表計算・プレゼン・長時間の作業での推論力」を強みと説明。簡単な依頼ではモデルの差はほぼ出ないという評価もあります。 [7][8][12]
Claudeがいるから成り立った新機能がある ○ ある Researcher の Critique と Model Council、そして Copilot Cowork。いずれも下の行で詳しく。 [2][3][6]
Claudeが関わる新機能
Critique：GPTの下書きをClaudeが査読してから出す △ Frontier 出典の信頼性・網羅性・引用の正確さを別モデルがチェック。早期アクセス制度（Frontierプログラム）と有償ライセンスが前提。 [3]
Model Council：同じ質問をGPTとClaudeに同時に調べさせて比べる △ Frontier 2本のレポートをそのまま残し、「一致点・相違点・それぞれ独自の指摘」をまとめた要約を付けてくれます。 [3][6]
Copilot Cowork：長く何段階もある仕事をまとめて任せる △ 従量課金へ AnthropicのClaude Coworkの技術を統合したもの。9月25日の発表で、今後はCopilot Credits（使った分だけ払う仕組み）での課金対象とされています。 [2][10][11]
どこでClaudeを選べるか
Word・Excel・PowerPoint・Copilot Chat でモデルを選ぶ ○ 可 有償のCopilotライセンスが必要。管理者がAnthropicを許可している必要あり（日本を含む大半の商用テナントは既定で許可）。Excelでは閉じると既定モデルに戻ります。 [5][7][8][9]
Researcher・Copilot Studio でモデルを選ぶ ○ 可 2025年9月から最初に対応した場所。Copilot Studioではエージェントの手順ごとにモデルを使い分けられます。 [1][8]
Outlookの下書き・Copilotノートブック内でClaudeを選ぶ ✕ 記載なし 公式の提供先一覧に登場しません（別の調査メモで確認済み）。 [7][8]

注意点 Caveats

  • 既定は「Auto」で、Autoが中でClaudeを使うこともあります。Autoは依頼ごとに合うモデルを自動で選ぶ仕組みです。「Claudeを選ばない限りClaudeは使われない」わけではないので、比較デモでは明示的に選び分けてください。
  • 料金体系が変わり始めています。9月25日の発表で、Coworkや上位のフロンティアモデルはCopilot Credits（使った分だけ払う仕組み）へ移る方針が示されました。管理者が支出ポリシーを有効にするまで課金はされないとされていますが、「Claudeを選ぶと追加料金がかかるのか」は勉強会で必ず聞かれるので、当日までに公式ブログ [11] の本文を確認しておくのが安全です。
  • 管理者設定と地域で出る・出ないが変わります。日本を含む大半の商用テナントでは既定でオンですが、管理者がオフにしていれば選択肢に出ません。EU/EFTA・英国は既定オフ、政府向けクラウドは対象外です。
  • データの扱いが他モデルと異なります。AnthropicはMicrosoftのサブプロセッサー（処理の委託先）として扱われ、EUデータ境界の対象外です。機密度の高い情報を扱う部署向けに説明する場合は、情報システム部門の判断を先に確認してください。
  • 名前が似た別製品と混同しないように。Anthropicが自社で提供する「Claude for Microsoft 365」（Word・Excel・PowerPoint・Outlook用アドイン）はClaude側の契約が必要な別製品です。また「Copilot Cowork」（Microsoft）と「Claude Cowork」（Anthropic）も別物です。今回の話はあくまで「M365 Copilotの中でClaudeを選ぶ」ことです。
  • モデルの版名はすぐ古くなります。この1年で Opus 4.1 → 4.7 → 4.8 → 5 → 5.5 と入れ替わっています。資料に版名を書く場合は「2026年9月時点」と添え、当日は実機のモデル選択画面で確認してください。
  • AIの回答は毎回少しずつ変わります。デモで狙った差が出ないこともあるため、事前に何度か試し、うまくいった結果のスクリーンショットを予備として用意しておくと安心です。
