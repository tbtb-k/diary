AI活用事例Copilot Studio2026年10月23日／建設・設計業（Dunaway）・法規制の調査

都市ごとの条例を調べる時間が約9割減りました（設計・エンジニアリング会社 Dunaway）

米国テキサス州の設計会社 Dunaway では、エンジニアが50以上の市の条例や基準を探して読むのに、年間1万時間以上をかけていました。

そこで Copilot Studio（ノーコードでエージェントを作れる Microsoft のツール）を使い、市ごとの条例に答える「City Code Analyst」を作りました。

Dunaway は、条例について質問して調べる時間が約90%減り、年間1万時間以上を取り戻せたと公表しています。

01こんな場面、ありませんか

「このルール、どこに書いてあったかな」と、古い PDF やウェブサイトを行き来して探した経験はありませんか。

Dunaway では、市ごとに条例が違い、しかも頻繁に改正されます。資料は各市のサイトや社内サーバーの古い PDF に散らばり、500ページ以上のマニュアルもありました。エンジニアが複数の市のルールを同時に確認するのは大変な作業でした。

02やってみたこと

Copilot Studio は、文章で指示や資料を与えるだけで、チャット形式のエージェント（AI の担当者）を作れる Microsoft のツールです。今回は、条例の資料を自動で集めて整える仕組みと組み合わせています。

資料の一覧表は、若手エンジニアが専門家の助言をもとに Excel で作りました。資料は SharePoint（社内の共有ファイル置き場）に保存され、Dataverse（Microsoft のデータ置き場）を通じてエージェントが参照します。完成したエージェントは Teams で使えます。

  1. 外部の会社（MicroAge）と、2か月の集中講座で Power Platform と Copilot Studio を学びました。
  2. 各市に必要な資料、入手先、補足情報を Excel の一覧表にまとめました。
  3. Power Automate（作業を自動化するツール）で、毎週、資料を集めて SharePoint と Dataverse に入れる流れを作りました。
  4. エージェントは出典のページつきで答え、判断が難しい質問は専門家に回します。市ごとに知識を分け、別の市のルールが混ざらないようにしています。

※ 手順の順序は、公開記事の説明を読みやすく並べ直したものです。実際の画面操作や設定の細かい内容は公開されていません。

03どう変わったか

これまで

市ごとに条例を探して読み、複数の市のルールをエンジニアが自分で突き合わせていました。調査に年間1万時間以上かかっていました。

いま

質問すると、出典ページつきの回答が返ります。必要なら専門家に確認を回せます。

1万時間以上、約90%減、50以上の市、毎週の更新、2か月の講座は、いずれも Dunaway が公表した数字です。ただし自社の報告であり、第三者の検証ではありません。誤答率などは公表されていません。

04明日から試すには

  1. 自分の部署で、「探すのに時間がかかる資料」を1つ選びます。
  2. その資料の一覧表（名前・置き場所・更新の頻度）を Excel で作ります。
  3. Copilot Studio で、その資料だけを知識にした小さなエージェントを作り、同僚2〜3人に試してもらいます。

準備するのは、資料の一覧と、試してくれる人です。Copilot Studio を使えるかどうかは、ライセンスや社内の設定で変わりますので、管理者にご確認ください。

05つまずきやすいところ

集めて整える作業が、いちばんの難所でした

記事によると、ハッカソン（短期の集中開発イベント）では、データを集めて Copilot Studio に取り込む作業が最大の課題でした。条例は頻繁に変わるため、資料を更新する流れを定期的に動かし続ける必要もあります。

Dunaway は、条例が複雑なため、社内での品質確認は今も必要だと述べています。エージェントは確認を助けるもので、置き換えるものではありません。AI の回答は必ず出典を開いて確かめ、機密情報を含む資料を入れるときは、閲覧できる人の範囲を先に決めましょう。

06おわりに

この事例は、AI を賢くすることより、正しい資料を最新の状態で届けることが成果を左右することを示しています。条例以外にも、社内規程や製品マニュアルなど、更新が多い資料なら同じ考え方が使えます。

自分の職場に置き換えると、総務への問い合わせが多い社内規程や、改訂の多い手順書があれば、最新版だけを知識にした小さなエージェントを作ってみる価値があります。
