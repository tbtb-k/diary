AI活用事例Copilot Studio2026年11月17日／化粧品（The Estée Lauder Companies）・マーケティングと市場調査

消費者データ集めが「数週間」から「数分」に。エスティ ローダーは社内の調査資料に答えるAIを作りました

化粧品大手の The Estée Lauder Companies（ELC）では、消費者や市場の調査データが PDF やスライド、表計算ファイルに散らばり、必要なデータを集めるのに数週間かかっていました。

そこで Copilot Studio で、社内の調査資料をもとに質問に答える AI エージェント「ConsumerIQ」を作りました。

その結果、データを集める時間が数週間から数分になり、同じ調査を重ねてしまう無駄もなくなったと公表しています。

01こんな場面、ありませんか

新しい企画を考えるとき、「前に似た調査をしていなかったっけ？」と社内を探し回る。結局見つからず、同じような調査をもう一度お願いしてしまう。資料はどこかのフォルダにあるのに、誰も全体を知らない。そんな場面は、調査や企画の仕事でよくあります。

ELC は、約25のブランドを150の国と地域で展開しています。消費者・市場・業界のデータは、PDF、PowerPoint、スプレッドシートの形で社内のあちこちにありました。どのチームも、手に入るデータのすべてを知ることはできません。そのため調査が重複したり、消費者向けの施策に移るのが遅れたりしていました。データを集めるだけで数週間かかっていました。

02やってみたこと

使ったのは Copilot Studio（プログラムをほとんど書かずに、AI エージェントを作れる Microsoft のツール）です。裏側では Azure OpenAI Service（Microsoft のクラウドで使える生成 AI）を使っています。ELC が Copilot Studio を選んだのは、すでに使っていた Azure（Microsoft のクラウド）の環境とつながるからだと、ブランド技術の責任者は話しています。

ConsumerIQ はチャットの形で使います。社内に蓄積した知見と最新の調査をあわせて傾向を見つけ、ばらばらのデータをつなぎ、施策のヒントを返します。利用者は、世界のマーケティング、インサイト（消費者理解）、ブランドの各チームです。

  1. 社内に散らばっていた消費者・市場の情報を、まず1か所に集めました。
  2. Azure OpenAI を使い、資料の中のグラフや表、画像も読み取れるようにしました。
  3. Copilot Studio でチャットの入り口を作り、「ナイトクリームの傾向は？」「毎日運動する人のマスカラの傾向は？」のように、ふつうの言葉で質問できるようにしました。
  4. 答えには出典を示し、利用者が元の資料をたどって確かめられるようにしました。

03どう変わったか

これまで

データが社内のあちこちにあり、集めるのに数週間かかっていました。同じような調査を重ねてしまうこともありました。

いま

質問すると数分で、出典つきの答えが返ってきます。調査の重複がなくなり、時間と費用の節約につながりました。

「数週間から数分に」は ELC が公表した内容です。節約できた金額や、利用者数は公表されていません。戦略施策の担当ディレクターは「エージェントを入れてから、チームは自分たちのスキルを高め、魅力的なマーケティング戦略や新しい製品づくりに集中できるようになった」と話しています（意訳）。

広がりも出ています。IT 部門で事業部門を支える担当ディレクターは、Copilot Studio を使って、自分が見られる資料から答えを引き出すサプライチェーン（調達から配送までの流れ）向けのエージェントも作りました。ELC は、サプライチェーンや製造の分野にも広げる計画です。

04明日から試すには

  1. 「前にも調べた気がする」とよく言われるテーマを1つ選び、関係する調査資料やレポートを1つのフォルダに集めます。
  2. Copilot Studio で小さなエージェントを作り、そのフォルダを知識として登録します。答えに出典を表示する設定も確かめます。
  3. チームの数人で、ふだん聞きたい質問を投げてみて、出典をたどって答えが正しいか確かめます。

準備するもの：AI に読ませてよい調査資料と、内容をよく知るメンバーです。Copilot Studio を使えるか、Azure の生成 AI とつなげるかは、ライセンスや社内の設定で変わります。最初は情報システム部門に相談してください。

※ 04 の3ステップは、Copilot Studio の一般的な作り方で補っています。ELC が実際に使った設定は公開されていません。

05つまずきやすいところ

まず資料を1か所に集めるところから

ELC は AI を作る前に、散らばっていた情報を1か所に集めました。グラフや画像に大事な情報が入っている資料も多いため、それらを読み取れるようにする工夫も必要でした。出典では、全体の仕組みは複雑だとも書かれています。

社内で真似するときは、調査資料の中に社外秘や個人情報がないか、誰が見てよい資料かを先に決めましょう。また、AI はもっともらしい間違い（ハルシネーション）をすることがあります。ELC のように出典を表示させ、大事な判断の前には元の資料を人が確かめてください。

06おわりに

この事例のポイントは、「探す時間」を減らしたことで、人がもっと考える仕事に時間を使えるようになったことです。社内にあるのに見つからない知識を、出典つきで引き出せるようにする考え方は、マーケティング以外にも使えます。

自分の職場に置き換えると、過去の提案書や企画書、顧客アンケートの結果、技術の検証レポートなど、「たしか前にやった」資料がたまっている業務が候補になりそうです。
