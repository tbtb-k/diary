AI活用事例Agent Builder2026年10月11日／IT・ソフトウェア（Microsoft 社内）・社内でのエージェント作成の広げ方

AI エージェントの作り手を月2,000人から20,000人に増やした Microsoft は、まず「資料を読んで答える小さなエージェント」から始めさせました

Microsoft の社内 IT 部門（Microsoft Digital）は、開発者ではない社員にも、自分の仕事に合った AI エージェントを作ってもらいたいと考えていました。

そこで、Microsoft 365 Copilot の Agent Builder（資料を読んで答えるエージェントを、自然な文章で指示して作れるツール）を入口にして、研修や相談会で作り手を支えました。

広報の担当チームは、過去の報告書をもとに社内向けキャンペーンの効果を予測するエージェントを作りました。Microsoft は、エージェントを作る人が「月約2,000人から20,000人」に増えたと公表しています。

01こんな場面、ありませんか

「この施策は、前回と同じくらい読まれそうか」と聞かれて、過去の報告書や数字を何本も開いて調べ直す。担当者の頭の中にしかない目安に頼っていて、人が変わると分からなくなる。そんな場面は、どの職場にもあります。

Microsoft Digital の社内向け広報のチームも、社内キャンペーンがどのくらい届き、どのくらい効果がありそうかを、手軽に予測できる方法を求めていました。

02やってみたこと

Agent Builder は、Microsoft 365 Copilot の中で、資料を読んで答える簡単なエージェントを自然な文章で作れるツールです。読ませる先には、SharePoint（社内の共有ファイル置き場）やウェブサイトなどを選べます。

広報チームは、プロジェクトの報告書、複数年・複数チャネルの分析、比較の基準になるデータを SharePoint の1つのフォルダーにまとめ、それだけを読む「Campaign Prediction Agent」を作りました。

  1. 報告書、分析結果、比較用のデータを、1つの SharePoint フォルダーに集めます。
  2. Agent Builder で、エージェントの役割と、読ませるフォルダーを決めます。
  3. 質問をすると、届きそうな範囲、全体の効果、予測の確からしさ（測定の信頼度）が、チャネルごとの内訳つきで報告されます。

※ 手順2は、Agent Builder の一般的な作り方で補っています。この広報チームが実際に書いた指示文や設定は公開されていません。

03どう変わったか

これまで

キャンペーンの効果を見積もるために、過去の資料を自分で探して読む必要がありました（出典の説明にもとづく整理です）。

いま

キャンペーンについて質問すると、チャネルごとの届く範囲・効果・予測の確からしさが、1つの報告として返ってきます。

このエージェント単体の削減時間などは公表されていません。次の数字は、Microsoft が公表した、エージェントを作る取り組み全体のものです。月に作る人は「約2,000人から20,000人」へ、作る際に感じる手間は「約50%から5%」へ変わりました。

04明日から試すには

  1. 「いつも同じ資料を見て答えている」業務を1つ選びます。過去の報告書を見て見積もる仕事も候補です。
  2. 使ってよい資料を1つのフォルダーにまとめます。内容が古い資料や、間違いのある資料は先に外しておきます。
  3. Agent Builder で、そのフォルダーだけを読むエージェントを作ります。説明を具体的に書き、数人で試してください。

必要なもの：Microsoft 365 Copilot の利用環境と、読ませてよい資料です。Agent Builder が使えるかどうかは、会社のライセンスや管理者の設定で変わります。

05つまずきやすいところ

資料の質が、そのまま答えの質になります

出典は、エージェントの質は元になる資料の質に左右されること、「プロンプトで十分か、エージェントにする価値があるか」が最初は分かりにくいこと、実行や自動化を求める声は Agent Builder の範囲外で、Copilot Studio（動作の自動化までできるツール）へ案内が必要だったことを挙げています。作りすぎたエージェントの管理も課題で、Microsoft では60日使われないものに通知と自動の整理をかけています。

社内で真似するときも、読ませてよい資料か、見せてよい相手かを先に決めましょう。AI の予測や回答は間違うことがあるので、重要な判断は元の資料で確認してください。

06おわりに

この事例のポイントは、道具を配るだけでなく、研修・相談会・社員同士の紹介で「いつ作ると役に立つか」を伝えたことです。Agent Builder で情報を扱い、動作の自動化が要るときは Copilot Studio へ進む、という使い分けも示されています。

自分の職場に置き換えると、過去の報告書や議事録が溜まっている部署は、同じ型で「過去の資料から目安を答えるエージェント」を作れそうです。まずは1つのフォルダーと1つの質問から始めてみてください。
