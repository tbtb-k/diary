AI活用事例Copilot Studio2026年10月21日／人材移動支援（Graebel）・サービス注文のメール処理

注文メールの手入力を減らす――Graebel が Copilot Studio で作った「画面を操作するエージェント」

転居・赴任支援の Graebel では、届いた注文メールを担当者が読み、専用システムへ手で入力していました。

そこで Copilot Studio を使い、メールを読み取って、システムの画面を人のように操作して登録するエージェントを作りました。

ただし、時間の削減などの数字は公表されておらず、まだ限られた注文の種類での試行段階です。

01こんな場面、ありませんか

取引先から届く依頼メールを読み、書式がばらばらな内容を、別のシステムに一件ずつ打ち込む。忙しい時期ほど、遅れや入力ミスが心配になる。そんな作業はないでしょうか。

Graebel（従業員は1,000〜9,999人規模）は、世界各地で人の転居を支援する会社です。依頼の多くは、クライアントやパートナーから、メールで届きます。そこには、対象者の情報、作業の範囲、期限、守るべきルールが書かれています。運用チームはこれを読み、自社の専用システム「globalCONNECT」へ手で入力していました。手間とコストがかかり、メールの形式がまちまちなため、間違いも起きやすい状態でした。しかも、このシステムはこの作業用の API（外部のソフトがつながるための窓口）を持っていませんでした。

02やってみたこと

Copilot Studio は、ノーコード（プログラムを書かない方法）が中心の、エージェント作成ツールです。Graebel は、これに Azure AI の文章読み取りの機能と、コンピューター利用（computer use：AI が人のように画面を見て操作する機能）を組み合わせました。作ったのが「Graebel Service Order Agent」です。パートナーの GET AI と一緒に進めました。

API がないため、エージェントは訓練を受けた担当者と同じように、システムの画面から入力します。自信が低いものや例外、承認が必要なものは、人が確認します。

  1. 決めたメールの受付口を見張ります。
  2. Azure AI Content Understanding（文書から必要な項目を取り出すサービス）で、ばらばらの文面を、決まった形の項目に整理します。
  3. サービスごとのルールと、守るべき条件を確認します。
  4. コンピューター利用の機能で、globalCONNECT の画面から登録します。
  5. 自信が低いもの、例外、承認が必要なものは、人の確認に回します。

03どう変わったか

これまで

担当者がメールを読み、内容をシステムに手で入力していました。忙しい時期は処理が遅れがちでした。

いま

対象の注文メールは、エージェントが読み取り、画面から登録します。例外や迷うものは人が確認します。

数字は、出典では公表されていません。記事には、時間の短縮、処理の速さ、正確さの数字は書かれておらず、成果は「初期のもの」「質的なもの」とされています。現在は、件数の多い一部の注文の種類での試行です。同社は30種類を超える関連サービスがあり、今後それらに広げられる設計だと説明しています。

04明日から試すには

  1. 「メールを読んで、別のシステムに入力する」作業を1つ選びます。
  2. 入力に必要な項目と、人が判断している例外の条件を書き出します。
  3. まずは、項目を取り出して表にするところまでを試します。登録の自動化は、そのあとです。

準備物は、実際のメールの例と、入力先の項目の一覧です。画面を操作する機能が使えるかどうかは、ライセンスや社内の設定で変わります。

05つまずきやすいところ

人の確認を残すことが前提です

記事によると、Graebel はAPIのない古いシステムへの対応、ばらばらな形式のメール、守るべきルールの管理に取り組みました。そのため、自信が低いものや例外は人が確認する設計にしています。画面操作の自動化は、手順書の変更に弱い従来の方法より、保守の手間が減ると記事は説明しています。

まねるときは、AI に画面を操作させる権限を、必要な範囲に絞ってください。メールには個人情報が含まれるため、扱える人と保存先も先に決めます。AI は、もっともらしい間違いを答えることがあります。登録した内容は、最初のうちは必ず人が見比べましょう。

06おわりに

この事例の要点は、API がない古いシステムでも、画面を操作する方法で自動化の入口をつくれることです。同時に、確認を人に残し、小さな範囲から始めている点も参考になります。

自分の職場に置き換えると、メールや申請書を読んで、別の画面に転記している作業が候補です。まずは件数の多い1種類だけに絞り、読み取りの精度を人がチェックしながら確かめるのが、安全な始め方です。
