Coworkの「/app」で作ったアプリ、クレジットはどこから引かれる？

Copilot Cowork の App スキル（/app）で作り、Microsoft のクラウドに公開して他の人に共有したアプリについて、クレジットが「いつ」「誰の枠から」減るのかを公式ドキュメントで確かめてまとめました。

調査日
2026-10-21
対象
Copilot Cowork の App スキル（Frontier プレビュー）と、アプリの公開先である Copilot Managed Runtime（プレビュー）

結論

作るときは作った人の枠から、使うときは使った人ひとりひとりの枠から引かれます。お財布（クレジットの残高）は会社全体で1つです。

アプリを作ったり直したりする分は、作成者が入っている Cowork 用の「支出ポリシー」から消費されます[2][3]。公開後に誰かがアプリを開いて使う分は、作成者ではなくその利用者本人に計上されるので、管理者は利用者向けに別の支出ポリシーを用意する必要があります[2][3][7]。利用者に Microsoft 365 Copilot ライセンスは要りませんが、Power Apps Premium ライセンスかクレジットの割り当てのどちらかは必要です[3]。

先に押さえておきたい言葉

Copilot Credits（クレジット）
Cowork などの従量課金で使う共通の「ポイント」。使った量に応じて減ります。
支出ポリシー
「誰が」「どのサービスで」「月にどこまで」クレジットを使ってよいかを決める、管理者が作るルールです。
Copilot Managed Runtime
Cowork で作ったアプリが置かれる、Microsoft が運用するクラウド上の置き場所です。
API 呼び出し
アプリが裏側で行う1回1回の処理のこと。アプリを開く、データを1件読む・書く、などが該当します。

作ってから使われるまでの流れと、お金が動くところ

  1. 作る・直す

    C作成者の Cowork 枠から消費[2]

  2. 公開する

    C公開も API 呼び出し1回として数えられます[3]

  3. 共有リンクを送る

    送るだけなら消費なし。ただし受け取った人に使う権利は付きません[3]

  4. 開いて使う

    C操作ごとに 0.1 クレジットを利用者本人の枠から消費[3]

アプリは Microsoft のクラウド上で動き、会社の Microsoft Entra アカウントでサインインして使います。利用者は専用ポータル（managedapps.cloud.microsoft）からも自分が使えるアプリを開けます[4]。

共有された人は、3パターンに分かれます

原則ゼロ

Power Apps Premium を持っている人

アプリを使ってもクレジットは減りません。1日のリクエスト上限を超えた分と、Work IQ API などの別サービスはクレジットで払います[2][3]。

使った分だけ

支出ポリシーに入っている人

API 呼び出し1回につき 0.1 クレジットが、その人の枠から減ります。管理者は1人あたりの上限も決められます[3][7]。

途中で止まる

どちらにも当てはまらない人

開けますが警告が出て、20回操作するか5分使うと（早いほう）ブロックされます。プレビュー期間中の動きです[2]。

Microsoft 365 や Dynamics 365 に最初から付いている Power Apps の利用権では、このアプリは動かせません[3]。

色付きの行が、今回いちばん知りたかった点です。

どのくらい減るの？

クレジットの単価（従量課金の定価）

$0.01／1 クレジット

100 クレジットで $1。前払いプラン（P3）は量に応じて 5〜20% 引きで、使い残しは1年で失効します[5]。

アプリを動かすときの単価

0.1クレジット／API 呼び出し1回

10回の呼び出しで 1 クレジット（$0.01）。AIを使う Work IQ API やエージェントは別料金です[3][5]。

API 呼び出しとして数えられる主な操作[3]

  • アプリを開く（起動する）
  • コネクタ経由でデータを読む・書く（レコードの読み込みや保存など）
  • アプリを公開する

作るときの目安（1本あたり）[6]

規模Microsoft が挙げている例クレジット金額の目安
軽め研修の日程・資料を見られて、感想を送れるハブ。管理用ページ付き250〜450$2.5〜4.5
中くらい今日対応が必要な相手と理由を一覧にし、担当者がフォロータスクを記録できるアプリ400〜750$4〜7.5
重め複数のデータ元と連携し、承認ページや例外処理、エージェント呼び出しまで持つ監査用ワークスペース700〜1,350+$7〜13.5+

動かすときの目安（1アプリ・1か月あたり）[6]

規模使われ方クレジット／月金額の目安／月
小さめ数人が使うフォームなどの簡単なアプリ。コネクタの利用は少なめ10〜50$0.1〜0.5
部署向け複数のコネクタを使い、部署で毎日ほどほどに使うアプリ300〜500$3〜5
全社向け大勢が使い、裏側の処理やコネクタの通信が多いアプリ3,000〜5,000$30〜50

どれも Microsoft が出している計画用のざっくりした目安で、実際の請求額を約束するものではありません[5][6]。

ざっくり試算してみる

Power Apps Premium を持っていない利用者が、公開済みのアプリを1か月使った場合の「使う分」だけを計算します。

API 呼び出し／月2,200 回
消費クレジット／月220
金額の目安／月$2.20

計算式：人数 × 開く回数 ×（起動1回＋読み書き回数）× 0.1 クレジット。読み書き1回をAPI呼び出し1回と仮定した試算です。実際の回数はアプリの作りで変わり、AI機能（Work IQ API・エージェント）を使う場合は別料金が加わります。

管理者が設定するところ（設定する順）

  1. 作れるようにする

    テナントを Frontier プログラムに参加させ、Microsoft 365 管理センターの アプリ > 概要 でアプリを作れる人を有効にします[2][8]。

  2. お財布を用意する

    Copilot > Cost management で従量課金をオンにし、支払い方法（Azure サブスクリプションでの後払い、前払いプランなど）を設定します[7]。

  3. 作る人の枠

    Cowork を対象にした支出ポリシーに、アプリを作る人を入れます。Cowork を見えるようにするだけでは App スキルは使えません[2]。

  4. 使う人の枠

    「Copilot Managed Runtime」を対象にした支出ポリシーを作り、アプリを使う人やグループを入れます。Power Apps Premium を持つ人は入れなくても使えます[3][7]。

  5. 上限を決める

    ポリシー全体の上限と1人あたりの上限、上限に近づいたときの通知を設定します[3][7]。

  6. 使われ方を見る

    Cost management の消費の画面で、ポリシー別・ユーザー別・サービス別にどれだけ減ったかを確認できます[7]。

説明するときに外せない注意点

  • プレビュー

    仕組みも金額も変わる可能性があります

    App スキルは Frontier プレビュー、Copilot Managed Runtime は有償のパブリックプレビューです。一般提供の前に価格や仕組みが変わることがあると明記されています[1][5]。

  • 自動追加

    既存の支出ポリシーに、知らないうちに含まれることがあります

    支出ポリシーは「新しいサービスを自動で追加する」設定が最初からオンです。既存の Cowork 用ポリシーが Copilot Managed Runtime までカバーしていないか見直してください[7]。

  • 共有範囲

    リンクを持つ人は、アプリのデータも全部見られます

    共有リンクを受け取った人は、アプリとその中のデータすべてを使えます。渡す相手は必要な人だけにします[1]。

  • 表現の差

    「Copilot を使える人」と「Copilot ライセンス不要」

    Cowork の手順ページは共有相手を「組織内で Microsoft 365 Copilot を使える人」と書き、ライセンス FAQ は「利用者に Microsoft 365 Copilot ライセンスは不要」と書いています。有償ライセンスのない人も使える前提と読めますが、実際のテナントで一度確かめるのが安全です[1][3]。

  • 作る人の条件

    作成者には別途ライセンスが要ります

    作る側は Microsoft 365 Copilot ライセンス、Cowork へのアクセス、Frontier への参加が必要です。Copilot ライセンスに Cowork の利用分は含まれず、別にクレジットがかかります[2][8]。

  • Studio との違い

    Copilot Studio で作ったアプリは「作る分」の管理場所が違います

    Copilot Studio で作る分は環境単位で Power Platform 管理センターから管理します。使う分はどちらで作っても利用者単位です[2][8]。
