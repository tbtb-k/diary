調査メモ 2026-10-29 時点

Frontier Transformation Engineer バッジ（FTB）の取り方

Microsoft のパートナー企業向けバッジ「Frontier Transformation Engineer」を取るために、何を・どこで・どんな順番で済ませればよいかを、公式情報をもとに整理しました。会社単位で目指す「Frontier Partner」認定との関係もあわせて載せています。

調査日
2026-10-29
対象
Frontier Transformation Engineer バッジ（個人向け）と、Frontier Partner スペシャライゼーション（会社向けの認定）
呼び方
「FTB」は公式の略称ではありません。正式名は Frontier Transformation Engineer badge で、Microsoft のブログでは「Frontier Engineer Badge」とも書かれています[1]。

結論

資格試験に3つ合格し、オンラインのテスト6本（Project Ready 5本と HVE 1本）をそれぞれ80%以上で通過すると、バッジが発行されます。

対象は、Microsoft パートナー企業で AI エージェントを設計・構築する技術者（ソリューションエンジニアやアーキテクトなど）です[1][2]。進み具合の管理と申請は、パートナー向けの学習サイト「Partner Skilling Hub（LevelUp）」で行います[8]。資格試験は受験料がかかり、全パートナー向けの無料バウチャーはありません[5]。

  1. STEP 1 ／ 資格

    資格試験に合格する

    3つ合格

    GH-300AI-103AB-100

    GitHub Copilot、Azure の AI アプリ開発、エージェント業務設計の3分野です[9]。

  2. STEP 2 ／ Project Ready

    実践コースのテストを通る

    5本×80%以上

    コースの受講は任意で、テストの合格が必須です[8]。

  3. STEP 3 ／ CoE・HVE

    開発の型のテストを通る

    1本×80%以上

    HVE コース（約1.5時間）が必須で、ほかの2コースは任意です[8]。

そのあと：発行を待つ

すべての確認が済むと発行されます。試験合格の反映には最大2〜3週間かかることがあります[8]。

会社として使うなら

会社の「Frontier Partner」認定には、このバッジを持つ人が5人必要です[4][6]。

用語をひとことで

Frontier Transformation
AI エージェントを前提に仕事のやり方を作り変える、という Microsoft の取り組みの名前です。
Partner Skilling Hub（LevelUp）
パートナー企業の社員向けの学習サイトです。バッジの進み具合もここで見ます。
Partner Center
パートナー企業が Microsoft との契約や認定を管理する管理画面です。
Project Ready
「すぐ案件に入れる」実力かどうかを確かめる実践コースのまとまりです。
HVE（Hypervelocity Engineering）
AI エージェントをとても速いペースで作って届けるための、開発の進め方の枠組みです。
CoE（Center of Excellence）
社内で AI 活用を広めたりルールを決めたりする推進チームのことです。
スペシャライゼーション
「この分野に強い会社」と Microsoft が会社単位で認める認定です。

会社の「Frontier Partner」認定との関係

個人のバッジとは別に、会社単位の認定「Frontier Partner スペシャライゼーション」の受付が 2026-09-30 に始まりました[6][7]。以前の会社向け「Frontier Partner バッジ」が、この認定に発展した形です[1]。次の3つを、同じ Partner Global Account（会社のパートナー登録の単位）で同時に満たす必要があります[4][6]。

会社の認定

4つ保有

  • Microsoft 365 Copilot
  • AI Apps on Microsoft Azure または AI Platform on Microsoft Azure
  • Data Security
  • Identity and Access Management
人の育成

5人 ＋ 3人

このバッジを持つ人が5人と、DP-600（Fabric Analytics Engineer Associate）に合格した人が3人必要です[4][13]。

第三者の監査

2年ごと

設計・構築・展開・統制・セキュリティ・運用まで提供できるかを、外部の監査で確かめます[4]。

バッジの5人と DP-600 の3人は、同じ人でも別の人でもかまいません[4]。つまり最小で5人のチームでも、うち3人が DP-600 も持っていれば人数の条件を満たせます。

認定を取ると得られるもの

  • お客様向けに表示できる Frontier Partner の認定バッジ
  • Frontier 関連の共同販売（Microsoft の営業と一緒に売る仕組み）の対象になる
  • Microsoft Agent の事前購入プラン（P3）のクレジットと Microsoft 365 E7 のライセンス
  • マーケティング素材や事例掲載の機会、申請から監査までのサポート窓口

注意点

  • 名前

    呼び名が揺れています

    FTB のほか、FTE、Frontier Engineer Badge、Titan（学習ジャーニーの名前）などと呼ばれます[1][8]。社内で話すときは正式名で確かめると話がずれません。

  • 確認

    細かい条件は LevelUp のページが出どころです

    80% の合格ラインやコースの時間数は、Microsoft の公式記事がリンクしている LevelUp のページ[8][9]によるものです。今回の調査環境からはこのページの本文を直接開けず、検索結果の抜粋で確認しました。始める前にページを一度開いて、最新の条件を確かめてください。

  • メール

    Learn プロファイルの紐付け方の案内が揺れています

    「個人メールのプロファイルに会社メールのものを紐付ける」と書いた版と、「LevelUp と同じ会社メールの Learn プロファイルを使う」と書いた版が見つかりました[8]。登録前に最新の案内を確認してください。

  • 期限

    バッジの有効期限は公式に書かれていません

    第三者のブログ[14]は「12か月」と書いていますが、公式の裏付けは見つかりませんでした。資格そのものには更新があり、DP-600 は12か月ごと[13]、GitHub の資格は2年[12]です。

  • 所属

    パートナー企業の社員であることが前提です

    Skilling Hub は会社のメールでしか登録できず、Microsoft も「パートナー企業の技術者向け」と説明しています[1][8]。パートナー企業に所属せずに取る方法は、公式には書かれていません。

  • 変更

    制度は動いている最中です

    2026年4月の発表から、認定の開始やイベントが続いています[1][7]。要件が変わることもあるので、日付を見ながら使ってください。
