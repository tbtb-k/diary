Copilot Studio のクレジットはいつかかる？

調査日2026-10-03
対象Copilot Studio のエージェント（標準ハーネス／GitHub Copilot ハーネス）
問いMicrosoft 365 Copilot ライセンスがあれば無料なのはどこまでか

Microsoft 365 Copilot ライセンスを持つ社員が、Teams や Copilot Chat の中で標準ハーネスのエージェントを使うぶんは、ほぼ追加課金なしです。ただし、ライセンスがあってもクレジットがかかる例外があります。

公式の料金表には「Microsoft 365 Copilot ライセンス ユーザーが使用」という列があり、クラシック回答、生成型の回答、エージェント アクション、テナント グラフ、AIツール、エージェント フローのすべてが「追加課金なし（No charge）」です[1]。条件は、社員向けの利用で、使う本人がライセンスを持ち、本人のIDで認証されて動くことです[1]。Web サイトなど Microsoft 365 の外のチャネルで使うと、ライセンスがあっても課金されます[3]。

ライセンスがあってもクレジットがかかるのは次のものです。

  • 課金コンピューター操作（CUA：画面を見てクリックや入力をするツール）[1]
  • 課金スケジュールやイベントなど、「エージェントがフローを呼び出すとき」以外のトリガーで動くエージェント フロー[1]
  • 課金GitHub Copilot ハーネスのエージェントとワークフロー。作る・試す段階からかかる[3][4]
  • 記載なし音声（電話応対など）。料金表に「追加課金なし」の扱いが書かれていない[1]
  • 推論人を介さずイベントで動く自律エージェント。「本人のIDで動く」という無料の条件に当てはまらないため、課金と見ておくのが安全[1]

追加課金なしになる3つの条件 すべて満たしたときだけ

料金表の「追加課金なし」は、Microsoft 365 Copilot ライセンス（ユーザーごとの契約）に含まれているという意味です。次の3つがそろったときに適用されます。

WHO / 使う人

本人がライセンスを持ち、本人のIDで使う

社員向け（Business to Employee）の利用で、使う人が Microsoft 365 Copilot ライセンスを持ち、その人のIDで認証されてエージェントが動くこと[1]。

WHERE / 使う場所

Microsoft 365 の中で使う

Teams、Copilot Chat、SharePoint などMicrosoft 365 のチャネルで使うこと。外部向け Web サイトなどで使うと課金[2][3]。

HOW / 作り方

標準ハーネスのエージェント

GitHub Copilot ハーネスのエージェントは、ライセンスに関係なく全部課金。作成中のプレビューや評価も含む[3][5]。

「無料」には上限があります。追加課金なしの利用は「フェアユース（公正な利用）の範囲内」に限られ、Microsoft は製品や使われ方の変化に応じて上限を見直すとしています[1]。

課金は「人」ではなく「エージェントと環境」の単位で数えられます。誰が何クレジット使ったかを個人ごとに請求に割り当てる仕組みではありません[3]。

クレジットが足りなくなったら 停止のルール

  1. 前払い容量の125%に達すると、エージェントが止まります。会話中のものは最後まで続きます。その後は利用者に「請求に問題があります」「使用制限に達しました」と表示され、容量が増えるか月が変わるまで使えません[1]。
  2. エージェント フローは、前払い容量を使い切った時点で新しい実行が止まります。エージェント本体の会話は動き続けます。実行中のフローは最後まで完了します[1]。
  3. 従量課金制をつないだ環境は止まりません。超えた分は Azure サブスクリプションに請求されます。Azure の予算アラートは通知だけで、利用を止めません[1][3]。
  4. クレジットは月ごとに使い切りで、翌月に繰り越せません。毎月の購入容量の範囲で適用されます[2]。

クレジットを抑える現実的な方法 3案

社員向けは Teams か Copilot Chat に公開する

ライセンス保有者が Microsoft 365 の中で使えば、標準ハーネスの基本機能は追加課金なしです。同じエージェントでも Web サイトに置くと課金されます[3]。

難易度：低追加コスト：なし

フローは「エージェントがフローを呼び出すとき」で作る

会話から呼ぶフローならライセンス保有者は課金なしです[1]。定期実行のような自動化は、Power Automate クラウド フローで作るとクレジットを使いません[1]。

難易度：低〜中追加コスト：Power Automate のライセンス範囲による

エージェントごとに月の上限を決める

Power Platform 管理センターの「ライセンス > Copilot Studio > エージェントの管理」で月間の上限と通知を設定し、超えたら止められます。特に GitHub Copilot ハーネスの試作には必須です[3][5]。

難易度：低（管理者作業）追加コスト：なし

説明するときの注意点 CAVEATS

  • 料金と条件はよく変わります。正式な情報は公式のCopilot Studio ライセンス ガイドで確認し、見積もりはエージェント使用量見積ツールを使ってください[1]。
  • 2025年9月1日に、課金の単位が「メッセージ」から「Copilot クレジット」に名前が変わりました。数量や従量課金の単価は変わっていません[2]。古い資料の「メッセージ」は同じものです。
  • 料金表の日本語版は機械翻訳で、注釈の意味が取りにくい箇所があります。このページは英語版の原文で確認しました[1]。
  • GitHub Copilot ハーネスでは、開発者環境と試用版環境も2026年9月1日から課金対象になりました。「試しに作っただけ」でもクレジットを使います[3][5]。一方、標準ハーネスは公開後から課金が始まり、エージェント フローのテスト実行は容量を消費しません[1][4]。
  • 前払いの Copilot クレジットは、Microsoft 365 側の Cowork や Work IQ などと共有されることがあります。Power Platform 管理センターと Microsoft 365 管理センターの両方で残量を確認してください[3]。
  • 自分で用意したモデル（Azure Foundry のモデルなど）を持ち込む構成は、この料金表の対象外で別に請求されます[1]。
  • 自律エージェントと音声の扱いは、料金表に「追加課金なし」の明記がなく、このページでは公式の計算例と無料の条件から判断しています。契約前に販売パートナーや Microsoft に確認するのが確実です。
