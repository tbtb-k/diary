INTRODUCTION

はじめに：ハーネスは3種類

Copilot Studio では、エージェントを作るときに、まずハーネス（エージェントの動き方を決める土台）を選びます。いまは3種類あります〔1〕。

前の冊子「Copilot Studio 活用事例集」は、スタンダード ハーネスの事例が中心でした。この冊子は「Microsoft Copilot ハーネスでなければ作れない仕事」だけを、5つのモデルケースで紹介します。

3つのハーネスを、ひとことで

スタンダード ハーネス

たとえるなら「マニュアルどおりの窓口係」

  • 会話の流れ（トピック）を作る人が決めます
  • 毎回同じ動きで、すぐに答えます
  • 向いている仕事：社内ヘルプデスク、申請の受付

前の冊子の事例の多くは、このハーネスです

この冊子

Microsoft Copilot ハーネス

たとえるなら「仕事を任せられる担当者」

  • ゴールを伝えると、手順を自分で考えます
  • ファイル作り・計算・長い仕事が得意です
  • 向いている仕事：資料作り、分析、点検

旧名は GitHub Copilot ハーネス。開発者向けのサービス「GitHub Copilot」とは別のものです

Customer Conversation ハーネス

たとえるなら「お客様窓口の担当者」

  • Web サイトのチャットや電話で、お客様と話します
  • 困ったときは人に引き継ぎます
  • 向いている仕事：お客様からの問い合わせ対応

2026年10月に加わった、お客様対応向けのハーネスです

FIVE POWERS

5つの「ならでは」と主役の早見表

Microsoft Copilot ハーネスにしかない力を5つにしぼり、1つの事例に1つずつ「主役」として割り当てました。

01

ファイルを作る

資料作りが得意な同僚

プレビュー

Word・Excel・PowerPoint・PDF を作って渡します。渡されたファイルを直して返すこともできます〔4〕。

スタンダードだとファイル作りは主な用途ではなく、答えはチャットの文章で返ります〔1〕

02

計算する

電卓と表計算ソフトを持った同僚

作業部屋（Bash コンテナ）で、表計算やグラフの道具を使います。大きなデータも正確に集計します〔2〕。

スタンダードだとこの作業部屋と、その中の道具は使えません〔2〕

03

長い仕事をやりきる

段取り上手なベテラン

ゴールから手順を組み立て、つまずいたら別のやり方を試します。長い作業や大きなファイルにも対応します〔2〕。

スタンダードだと作った道順どおりに動きます。想定外への備えも人が先に作ります〔2〕

04

手順書を持つ（スキル）

仕事のやり方のマニュアル

やり方・チェックリスト・見本を1つにまとめ、必要なときだけ開いて使います。複数のエージェントで使い回せます〔5〕。

スタンダードだとスキルは Microsoft Copilot ハーネスのエージェントだけの機能です〔3〕

05

覚えておく（メモリ）

付箋ではなく日記帳

順次一般提供

人ごとに、好み・直してほしいこと・続いている仕事を、会話をまたいで覚えます〔6〕。

スタンダードだとメモリはありません。変数は、その会話の間だけのメモです〔3〕

営業

商談準備パック

この事例の主役ファイルを作る

商談の前日に、要点メモと提案スライドがそろう

商談の相手と日時を伝えると、メール・会議メモ・顧客データ・製品資料を集めて、要点メモ（Word）と提案スライド（PowerPoint）を作ります。自社のひな形に沿った、そのまま直せるファイルで届きます。

使う力ファイルを作る主役長い仕事をやりきる

いま

  • 商談の前に、過去のメールや議事録を探して読み返すのに時間がかかります
  • 提案スライドは、毎回前の資料をコピーして作り直しています
  • 担当者によって、準備の深さにばらつきがあります

これから

  • 前日には、要点メモとスライドの下書きがそろっています
  • 担当者は「どこを強調するか」を考えて直すことに集中できます
  • 誰が作っても、自社のひな形どおりの資料になります

しくみ

  1. 相手と日時を伝える営業担当者
  3. 材料を集めるメール・顧客データなど
  5. 構成を考える伝える順番
  7. ファイルを作るWord・PowerPoint
  9. 人が確認直して商談へ

スタンダード「文章で答える」ところまで

vs

Microsoft Copilot ハーネス「ファイルで渡す」ところまで

スタンダードだと、ここができない主役：ファイルを作る

スタンダードで作ると

材料を集める▶要点をまとめる▶ここで止まるファイルにする
  • 答えはチャットの文章で返ります。資料にするには、人がコピーして貼り付けます
  • ひな形を読んで、スライドを組み立てる機能はありません

回り道するなら：差し込み用のフローを自分で組めば、決まった形の文書は作れます。ただし、スライドの構成を内容に合わせて変えるのは難しくなります。

Microsoft Copilot ハーネスなら

材料を集める▶要点をまとめる▶ファイルで渡す
  • Word や PowerPoint のファイルそのものを作り、チャットに「ファイルのカード」で届けます
  • 渡されたひな形を読み、その形に合わせて組み立てます
  • 「3枚目をもっと短く」と頼めば、ファイルを直して返します

公式ファイルの作成・編集は Microsoft Copilot ハーネスの特長で、スタンダードでは「主な用途ではない」とされています〔1〕。作ったファイルはチャットのカードからダウンロードできます〔4〕。

商談準備パック依頼から完成まで

  5. 作業部屋で計算集計・グラフ
  7. レポートにするExcel・PowerPoint

02 数字の分析レポート係 ｜ 主役の図解とつくり方

主役の図解作業部屋で計算する

渡すデータ

XLSX今月の売上.xlsx

日付地域商品金額
11/01東日本A12,800
11/01西日本C8,400
11/02東日本B23,100
11/02九州A6,900
… ほか 48,000 行

作業部屋（Bash コンテナ）

  1. 全部の行を読み込む
  2. 月×地域×商品で合計する
  3. 前年の同じ月と比べる
  4. 伸び・落ちの大きい順に並べる
  5. グラフを描く

表計算・グラフの道具最初から入っている。作る人はプログラム不要

できあがり

XLSX月次レポート（集計表・グラフ）

PPTX報告スライド（3枚）

11月の売上伸びた地域

表を「読んで」答える（スタンダード）

東日本の売上は、だいたい 1億2,000万円くらいだと思われます。

読める量に限りがあり、合計がずれることがあります

道具で「計算して」答える（Microsoft Copilot）

東日本の売上は 1億2,345万6,000円です（全48,000行のうち東日本の行を合計）。

計算の手順が残るので、同じデータなら同じ結果になります

つくり方

  1. Microsoft Copilot ハーネスで新しいエージェントを作り、指示に「毎月の売上を集計して報告する」目的と、見る切り口（地域・商品・前年比など）を書きます
  2. 売上データの置き場所（SharePoint など）を読めるようにし、レポートの見本を渡します
  3. 「数字は必ず計算で出す」「計算の手順を最後に書き添える」と指示に書きます
  4. 先月のデータで試し、手で集計した結果と合っているかを確かめてから使い始めます

最初の数か月は、人の集計と並べて答え合わせをすると安心です。

会話のイメージ

数字の分析レポート係Teams

11月の売上データです。いつものレポートをお願いします

全体は前年比 104％で、九州の商品Aが大きく伸びています。月次レポート（Excel）と報告スライド（3枚）です。

商品別の順位でも見たい

商品別に並べ替えたシートを追加しました。上位3商品で全体の 61％です。

準備するもの

  • 毎月の売上データ（列の名前をそろえる）
  • いまのレポートの見本
  • 手で集計した過去の結果（答え合わせ用）

BEFORE YOU START

はじめる前に：費用と管理

Microsoft Copilot ハーネスは、スタンダードとお金のかかり方がちがいます。作り始める前に、管理者と次のことを決めておきましょう。

いつから費用がかかる？

作る試す評価する使う

4つとも Copilot クレジットを使います。公開しないで試しているだけでもかかります〔12〕。Microsoft 365 Copilot のライセンスには含まれません〔11〕。開発者環境・試用版環境も、2026年9月1日から使った分の課金になりました〔11〕。

エージェントごとに上限をかける

通知止める今月の使用量月の上限

管理者が Power Platform 管理センターの「ライセンス」→「Copilot Studio」→「エージェントの管理」で、エージェントごとに月の上限・通知の目安・上限で止めるを設定できます〔11〕。

Microsoft 365 Copilot のライセンスで、まかなえる？

スタンダードMicrosoft 365 の中（Teams など）で使うぶんは、ライセンスでまかなえます

Microsoft Copilot ハーネスライセンスに関係なく、作る・使うのすべてが Copilot クレジットの対象です

出典：費用の管理のページの比較表〔11〕。細かい条件は契約によって変わるため、管理者に確かめてください。

知っておきたい決まりごと

費用は「環境」ごとに数える

使った人ごとではなく、エージェントが動く環境ごとに数えます。環境ごとに使える量を割り当てることもできます〔11〕。

公開できる場所

Microsoft Copilot と Teams（一緒に、または Teams だけ）、デモ用の Web サイト、Web アプリです。SharePoint などには公開できません〔9〕。

作ったファイル

1ファイル10MBまで。会話が最後に動いてから28日間残ります。機能はプレビューです〔4〕。

覚えたこと（メモリ）

人ごとに分けて保存し、28日間使われないと消えます。本人が見る・消すことができます〔6〕〔7〕。

答えるまでの時間

自分で段取りするぶん、答えるまでの時間やクレジットが増えることがあります。速さが大事な会話は、スタンダードも候補にします〔2〕。

管理者のルール

作れる人、使えるデータやコネクタ、共有できる相手は、管理者のセキュリティ ロールやデータ ポリシーで決まります〔10〕。

はじめる前のチェックリスト

  • 管理者と、エージェントごとの月の上限を決めた
  • 試す環境と、本番の環境を分けた
  • 公開先（Teams など）が使えるか確かめた
  • 読ませるデータの範囲と、作ったファイルの置き場所を決めた
  • 人が確認する場所（どこで止めて見るか）を決めた
  • 小さく試す範囲（1件・1か月分など）を決めた
