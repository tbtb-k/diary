Claude Opus 5.5とGPT-6 Solが、Microsoft Copilotのモデル選択に追加

何があった？
Microsoftは、Copilotで選べるAIモデルにAnthropicの「Claude Opus 5.5」とOpenAIの「GPT-6 Sol」を加えると発表しました。どちらも同じ日に各社から発表されたばかりの新モデルです。展開は順次で、アプリや環境によってはまだ表示されないこともあります。
嬉しい・注意点
すでに選べるClaude Opusが、新しい世代に入れ替わっていくイメージです。一方で、モデルが増えるほど「結局どれを選べばいいの？」という質問も増えていきます。
支援現場でのひとこと
「モデルは料理人、Copilotは同じ厨房」くらいのたとえで、選択肢が増えても使い方は変わらないと伝えると安心してもらえそうです。迷う人には「自動」のままで大丈夫、と添えるのがシンプルです。

出典：Microsoft Tech Community「More Models, One Copilot」／展開状況は M365 Copilot Connection の検証記事

2026/09/16Frontier9月下旬GA予定MC1473166

PowerPointのCopilotに「ブランドスキル」。組織の資料ルールを登録できる

何があった？
PowerPointのCopilotが参照する「Brand Kit（組織のテンプレート・画像・フォントのセット）」に、資料作りの指示書をMarkdownファイルの「スキル」として登録できるようになります。ブランド管理者が登録して有効にすると、利用者はその指示に沿ってCopilotに資料を作らせられます。Frontierでは9月中旬から、一般提供は9月下旬からの予定で、デスクトップ・Mac・Web版それぞれで告知が出ています。
嬉しい・注意点
「表紙はこの形」「1枚で言うことは1つ」のような社内ルールをCopilotに覚えさせられます。ただし登録できるのはブランド管理者だけで、登録しただけでは自動で使われず、有効化が必要です。
支援現場でのひとこと
お客様の組織で「ブランド管理者」が誰なのかを先に確認しておくと、「うちでも使いたい」と言われたときに話が早く進みます。

出典：Microsoft 365 Message Center Archive「MC1473166」

2026/09 中旬開発中RM571194–571196

Copilot Studio、消費量（コスト）を「作っている途中」から見える化へ

何があった？
Microsoft 365ロードマップに、Copilot Studioのコスト表示に関する3つの項目が追加されました。エージェントの評価（テスト）、モニタータブ、プレビューチャットの3か所で、それぞれどれだけ消費したかを内訳つきで確認できるようになる予定です。評価の項目は9月中の一般提供が目標とされています。
嬉しい・注意点
これまでは公開後に気づくことが多かったクレジットの消費を、テスト段階で把握できるのが大きな前進です。まだ「開発中」なので、画面や時期は変わる可能性があります。
支援現場でのひとこと
「クレジットがどれだけ減るのか不安」というお客様に、テスト画面の数字を見せながら説明できるようになりそうです。

出典：Microsoft 365 Message Center Archive「RM571195」／Kesslernity「Copilot Weekly 2026-W38」

2026/09/17国内説明会

日本マイクロソフトが「Microsoft IQ」を説明。AIに業務の文脈を渡す仕組み

何があった？
日本マイクロソフトが記者説明会で、社内の知識や背景情報をAIエージェントに渡す仕組み「Microsoft IQ」を紹介しました。組織内のやり取りから役割や文脈をつかむ「Work IQ」、複数のデータ基盤にあるビジネスデータをまとめる「Fabric IQ」、マニュアルや規程をAIが使える形にする「Foundry IQ」、Web上の最新情報を取り込む「Web IQ」の4つで構成されます。国内事例として、SCSKが業績変化の要因を特定する作業を数日から即日に縮め、作業時間を約50％短くした例が紹介されました。
嬉しい・注意点
Copilotの答えが「自分の仕事」に合わせて返ってくる理由を説明するときの材料になります。名前が似ていて混乱しやすいので、まずは「Work IQ＝Microsoft 365の中にある仕事の文脈」だけ押さえればOKです。
支援現場でのひとこと
「IQ＝AIに渡す社内の文脈」とひとことで言い換えると、一般社員向けの説明でも伝わりやすくなります。

出典：AI Watch「AIエージェントに業務の文脈を与える『Microsoft IQ』の真価」

GitHub CopilotにもClaude Opus 5.5とGPT-6 Sol／Lunaが登場

何があった？
GitHub Copilotのモデル選択で、Claude Opus 5.5とGPT-6 SolがPro+・Max・Business・Enterpriseプランで使えるようになりました。軽量なGPT-6 LunaはProプランでも使えます。VS Code、Visual Studio、JetBrains、Xcode、github.com、モバイルアプリなど幅広い環境が対象で、展開は順次です。
嬉しい・注意点
BusinessとEnterpriseでは、新しいモデルは初期設定で自動的に有効になります。使うモデルを絞っている組織は、管理者がモデルのポリシー設定を確認しておく必要があります。
支援現場でのひとこと
「新モデルは自動でON」という仕様は、ガバナンスを気にするお客様に必ず伝えておきたいポイントです。

出典：GitHub Changelog（Claude Opus 5.5）／GitHub Changelog（GPT-6 Sol・Luna）

2026/09/18GA一部展開中

GitHub Copilot週次アップデート：レビュー強化と「自動モデル選択」の3段階

何があった？
Copilotのコードレビューが、対応済みの指摘は次のレビューで自動的に解決済みにし、未対応の指摘は残すようになりました（一般提供）。モデルを自動で選ぶ機能には「効率重視」「バランス」「品質重視」の3段階が加わり、順次展開されています。
嬉しい・注意点
3段階はどれも同じモデル群から選ぶ仕組みで、違いは「コストと品質のどちらを優先するか」です。従量課金のBusiness・Enterpriseでは、利用者がクレジット上限の引き上げを申請して管理者が承認する機能も一般提供になりました。

出典：GitHub Changelog「GitHub Copilot weekly releases — September 14」

2026/09/17提供開始

GitHub Copilotの利用状況ダッシュボードで「機能ごとの定着度」が見えるように

何があった？
管理者向けのダッシュボードで、コード補完、エージェント編集、コードレビュー、クラウドエージェント、CLI、アプリなど7つの機能ごとに、定期的に使っている人数が見えるようになりました。「28日間のうち2日以上使った人」を定期利用者として数えます。
嬉しい・注意点
導入したのに使われていない機能がひと目で分かるので、次にどこを支援するか決めやすくなります。見るには、利用状況メトリクスのポリシーを有効にしておく必要があります。
支援現場でのひとこと
「28日で2日以上使えば定着」という数え方は、Copilot全般の定着施策でKPIを決めるときの参考になります。

Anthropic「Claude Opus 5.5」を公開。上位モデル並みの性能をより安く

何があった？
Anthropicが新モデルClaude Opus 5.5を公開しました。多くの作業で上位モデルClaude Fable 5.1並みの性能を出しつつ、前世代のOpus 5より運用コストを約40％下げたとしています。API料金は100万トークンあたり入力4ドル・出力20ドルで、AWS、Google Cloud、Microsoft Azureでも提供されます。
嬉しい・注意点
「高性能なまま安くなる」方向の進化です。他社製品への組み込みも速く、今回はMicrosoftとGitHubが発表と同じ日に対応を始めました。

出典：Anthropic「Introducing Claude Opus 5.5」

2026/09/22GA

OpenAI「GPT-6 Sol／Luna」を発表。API料金は前世代の半額に

何があった？
OpenAIがGPT-6シリーズの新モデルSolとLunaを発表しました。最上位のGPT-6 Astraで得た改良を、より安い価格帯に広げたモデルです。API料金は前世代の半額で、Solは100万トークンあたり入力2ドル・出力10ドル、Lunaは入力0.10ドル・出力0.50ドル。ChatGPTの有料プランやCodexでも使えます。
嬉しい・注意点
Solはバランス型、Lunaは小さな作業向けの軽くて安いモデル、という役割分担です。最も高性能なのは引き続きAstraです。

出典：OpenAI「Introducing GPT-6 Sol and Luna」

2026/09/17限定提供

OpenAI「Astra for Law」。法律業務向けに特化したGPT-6 Astra

何があった？
OpenAIが、GPT-6 Astraを法律業務向けに調整した「Astra for Law」を発表しました。米国の判例や法令を集めた検索インデックスと、法律分析向けの指示を組み合わせたものです。法律調査の評価では正答率54.0％と、Web検索だけのAstra（38.7％）を上回ったとしています。まずは選ばれた法律事務所向けで、APIは今後提供予定です。
嬉しい・注意点
対象は米国法なので、日本ですぐ使うものではありません。注目したいのは「汎用AIに専門知識と指示を足して精度を上げる」という作り方です。
支援現場でのひとこと
「汎用AI＋専門知識＝特化エージェント」の実例として、Copilot Studioでナレッジを足してエージェントを作る意味を説明するときに使えます。

出典：OpenAI「Introducing Astra for Law」

2026/09/18プレビュー

Google、Gemini EnterpriseからMicrosoft 365を操作できる機能をプレビュー

何があった？
GoogleのGemini Enterpriseに、OneDrive、Outlook、SharePoint、Teamsを操作する「アクション」が追加されました（パブリックプレビュー）。ファイルの移動や共有、予定への出欠の返信、SharePointのリスト項目の作成、Teamsのチャネル作成などができます。
嬉しい・注意点
他社のAIがMicrosoft 365の中まで操作しに来る流れです。M365のデータを外部のAIにつなぐかどうかは、情報システム部門が判断するポイントになります。
支援現場でのひとこと
「Copilot以外のAIからM365につなぎたい」という話が出たら、接続の許可や権限を誰が管理するかを最初に確認すると安全です。

出典：Google Cloud「Gemini Enterprise release notes」

Frontier（フロンティア）

今週のGrok、ブランドスキル、アプリ作成は、どれもまずここから始まりました

ひとことで

Microsoft 365 Copilotの新機能を、正式リリースより前に試せる「先行体験の枠」です。

たとえるなら

新メニューの試食会。お店（Microsoft）がまだ正式メニューに載せていない料理を、参加を決めたお客さん（組織）だけが先に食べられます。味や見た目は、正式メニューになるまでに変わることもあります。

押さえておきたいこと

  • 組織で使うには、管理者側で参加の設定が必要です。
  • 正式版になるまでに、機能や画面が変わったり、見送られたりすることがあります。
  • 「ニュースで見た機能がうちには出てこない」ときの理由のひとつです（もうひとつは「順次展開中」）。
勉強会での言い方：「ニュースで見た機能が出てこないときは、Frontier限定か、まだ順番待ちのどちらかであることが多いです。」
