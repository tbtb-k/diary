AI活用事例Copilot Studio2026年11月19日／鉄道物流（Rumo）・運転現場の手順確認

運転士が手順書を探す時間が、4分超から3秒になりました

ブラジル最大の鉄道物流会社 Rumo では、1,700人を超える運転士が紙の手順書を持ち歩き、走行中に疑問が出ると列車を止めて調べていました。

そこで Copilot Studio で、運転士がスマートフォンから質問すると、承認済みの手順書をもとに答える AI エージェント「RUTI Maquinista」を作りました。

手順を探す時間は平均4分超から3秒になり、年7,644時間の作業時間を取り戻したと公表しています。

01こんな場面、ありませんか

現場で「この場合の手順はどうだったか」と迷ったとき、分厚いマニュアルをめくるか、上司に電話して確かめるしかない。マニュアルが改訂されるたびに印刷し直して配り、古い版が手元に残っていないか心配になる。そんな悩みは、工場や店舗、倉庫など現場を持つ多くの職場にあります。

Rumo の運転士は、1人あたり約4kgの紙の手順書をかばんに入れて乗務していました。走行中に疑問が出ると、列車を止め、資料を探し、上司に連絡する必要がありました。運転士の一人は「列車を止める影響はとても大きい」と話しています（意訳）。改訂のたびに何千ページも印刷し直す負担もありました。

02やってみたこと

使ったのは Copilot Studio（プログラムをほとんど書かずに、AI エージェントを作れる Microsoft のツール）です。Rumo は Copilot Studio で、鉄道の現場に合わせた安全な AI エージェント「RUTI Maquinista」を作りました。答えのもとになる手順書は SharePoint（社内の共有ファイル置き場）に置き、文章の生成には Azure OpenAI（Microsoft のクラウドで動く生成 AI）を使っています。

エージェントが参照する情報は、すべて Rumo 自身の規程担当チームが更新しています。答えは承認済みの知識の範囲に限られます。

  1. Microsoft Entra ID（社員のアカウントを管理する仕組み）を使い、Rumo の社員だけが使えるようにしました。
  2. 規程担当チームが手順書を整え、AI が参照する範囲を承認済みの知識だけに限りました。
  3. Copilot Studio でエージェントを作り、SharePoint と Azure OpenAI につなぎました。
  4. 会社支給のスマートフォンに配りました。二段階認証、決まったアプリしか使えない「キオスク」設定、機密情報を分けて保管する仕組みを組み合わせています。
  5. 運転士は質問を入力するだけで、その場で答えを受け取れるようになりました。

※ 手順の順番は記事の記述をもとに整理したものです。Copilot Studio での具体的な設定内容は公開されていません。

03どう変わったか

これまで

約4kgの紙の手順書を持ち歩き、手順を探すのに平均4分以上。疑問が出ると列車を止めて、上司に連絡していました。

いま

スマートフォンで質問すると、平均3秒で手順が見つかります。運転士は「いまは全部が手のひらの中にある」と話しています（意訳）。

Rumo が公表した数字では、手順を探す時間が平均4分超から3秒になり、取り戻した作業時間は年7,644時間です。印刷しなくてよくなった紙は年130万ページで、投資は2か月以内に回収できたとしています。導入の最初の1か月半で、運転士の約50%が使い始めました。

04明日から試すには

  1. 現場で「よく迷う手順」を3つほど書き出し、それが載っているマニュアルを1つに決めます。
  2. そのマニュアルの最新版を、担当部署が管理する SharePoint の場所に置きます。古い版は置きません。
  3. Copilot Studio でエージェントを作り、その場所だけを知識に登録して、書き出した質問で答えを確かめます。

準備物は、最新版のマニュアルと、その内容に責任を持つ担当者です。Copilot Studio を使えるかどうか、社外の端末から使えるかどうかは、ライセンスや社内の設定で変わります。まず IT 部門に確認してください。

05つまずきやすいところ

安全にかかわる情報は「誰が・どこまで」を先に決める

Rumo では安全の手順を扱うため、社員だけが使えるようにし、答えの範囲を承認済みの知識に限りました。担当者は「二段階認証、必要な知識だけに絞った保管場所、キオスク」の3つを挙げています（意訳）。CTO（最高技術責任者）も、AI エージェントが広がるほど、機会と責任が同じだけ生まれると話しています（意訳）。

社内で真似するときは、マニュアルの更新担当を決め、古い情報が残らないようにしてください。AI はもっともらしい間違い（ハルシネーション）を答えることがあります。安全にかかわる判断では、答えのもとになった手順書の該当箇所を必ず確かめる運用にしましょう。機密の資料をうっかり知識に入れないことも大切です。

06おわりに

この事例のポイントは、AI に「何でも答えさせる」のではなく、担当チームが承認した手順書だけを答えのもとにしたことです。情報の持ち主をはっきりさせたうえで、現場の手元に届ける形は、安全手順に限らず、社内規程や作業標準など多くの分野で使えます。Rumo も、法務や技術部門などへの展開を検討しています。

自分の職場に置き換えると、たとえば店舗の接客マニュアル、倉庫の出荷手順、設備の点検手順などが当てはまります。「現場で迷ったとき、誰かに電話して聞いている情報」から始めると、効果が見えやすいでしょう。
