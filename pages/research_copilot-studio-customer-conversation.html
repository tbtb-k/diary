できること

Copilot Studio に加わった「Customer Conversation ハーネス」について、何ができるのか、作る画面はどう進むのか、実際にどう使われているのか、料金や日本で使うときの注意点まで、Microsoft の公式ドキュメントと公式ブログ（計34本）で確かめてまとめました。ハーネスとは「AIモデルを、決まった種類の仕事ができるエージェントとして動かすための土台（型）」のことです。日本語版の Microsoft Learn では「カスタマー会話ハーネス」とも書かれています。

結論

お客さま向けの「電話とチャットの窓口」を、受付役と専門係のAIチームで作り、解決できないときは人に引き継ぐための専用の型です。2026年10月21日にプレビューとして登場し、11月18日に一般提供（GA）になりました。

1つのエージェントが最初から電話（音声）とチャットの両方に対応し、受付役のエージェントが用件を聞き分けて、請求・配送・技術サポートなどの専門係（サブエージェント）に振り分けます。人への引き継ぎ（Teams Phone、メール、コンタクトセンター）や、声で本人を確かめる機能が最初から用意されているのが、ほかのハーネスとの大きな違いです[1][3][9][31]。

電話もチャットも1つでチャネルを先に選ぶ必要はなく、話し方の指示だけ「Speech」「Chat」で書き分けます[10]
困ったら人へ「Escalate」ツールで Teams Phone・メール・コンタクトセンターに会話ごと渡せます[9]
作る→試す→公開→見守るBuild・Preview・Evaluate・Deploy・Monitor のタブが1画面にそろっています[3]
日本の地域はまだ対象外対応地域の一覧（11/24更新）に日本がありません。日本リージョンの環境では作れない前提で計画してください[23]

いつから使える？ 提供状況の流れ

「新しく出た」という話は本当で、まだ出て1か月ほどの機能です。プレビューから一般提供までが短いので、古い記事の「プレビュー」表記と混ざりやすい点に気をつけてください。

  1. 2026-10-21
    パブリックプレビュー開始
    Copilot Studio ブログで発表。同じ日に、既存のコンタクトセンターにAIを足す新製品「Microsoft Contact Center Intelligence（CCI）」も発表されました[29][32]。
  2. 2026-11-04
    10月の新機能まとめで「プレビュー中」と紹介
    請求・アカウント・トラブル対応などの専門係を作れること、テスト・評価・公開・監視が一体になっていることが説明されました[30][28]。
  3. 2026-11-16〜17
    Microsoft Learn の説明ページが一斉に更新
    作成手順・音声設定・メモリなどの詳しいページがそろいました。検索エンジンに残る古い題名には「(preview)」が付いていますが、今のページ名からは外れています[3][4]。
  4. 2026-11-18（Ignite 2026 期間中）
    一般提供（GA）
    Copilot Studio 公式ブログが「now generally available（一般提供開始）」と明記。同じ日に CCI も一般提供になりました[31][33][34]。

補足：Learn の「What's new」ページ（11/12更新）は10月のプレビューの記載までで、GA の行はまだありません[28]。また GA 後も、会話形式のテスト、カスタム指標、REST API ツールなど一部の機能はプレビューのままです[18][22][8]。

ひとことで言うと：AIの「コールセンター」を1つ作る型

このハーネスで作るエージェントは「Customer Assist Agent（カスタマー アシスト エージェント）」と呼ばれます[3]。中身は、受付役が1人と、得意分野ごとの専門係が複数いるチームです。

たとえるなら

会社の代表電話です。受付の人（受付役）が「ご用件は？」と聞いて、経理・配送・サポートの担当部署（専門係）に回し、難しい話は上の人（人の担当者）に代わります。この「受付と部署の分け方」と「どこで人に代わるか」を、画面上で設定していくイメージです。公式も「専門係は、コンタクトセンターの部署のように互いに独立させるのがうまくいくコツ」と書いています[6]。

3つのハーネスの違い

Copilot Studio のエージェントは、作るときに3つのハーネス（型）のどれかを選びます。AIモデルが「考える頭脳」だとすると、ハーネスは「その頭脳に道具を持たせ、仕事の進め方を決める枠組み」です[2]。

会話の作り方
電話とチャットを1つで○すべてのエージェントが最初から音声とチャットの両方に対応。話し方の違いは指示の「Speech」「Chat」タブに書き分けます（各2万字まで）。[10][5]
受付役＋専門係のチーム○受付役から専門係へ振り分け。専門係の説明は1,024字まで、指示は2万字まで。指示の中で「/専門係名」と書くと、係どうしの連携も指定できます。[6][4]
AIの自由回答＋決まった手順の両立○「生成スキル」（指示を読んでAIが判断）と「トピック」（電話の自動音声案内のような決まった手順）を1つのエージェントで混ぜられます。[29][33]
会話の節目の動き（イベント）○会話開始、終了、エラー、無音検知、会話リセットなど。たとえば開始時にコンタクトセンターから渡された電話番号を受け取れます。[15]
情報と道具
参照できる資料（ナレッジ）△公開Webサイト、ファイル、Dynamics 365、SharePoint、Dataverse、Salesforce、ServiceNow。ただし本人のサインインが必要な資料はチャットだけで使えます（電話ではサインインできないため）。[7][3]
他システムの操作（ツール）○窓口向けのシステムツール、プロンプト、Power Platform コネクタ、MCP（AIと外部ツールをつなぐ共通ルール）、REST API（プレビュー）、ワークフロー。[8]
お客さまが送ったファイルを読む○PDF・TXT・CSV・XLSX・画像（15MBまで）を会話の中で分析。ファイルは保存されません。[12]
Word・Excel などのファイルを作る✕このハーネスの得意分野ではないと明記されています。資料作成が主役なら Microsoft Copilot ハーネスです。[1]
窓口ならではの機能
人への引き継ぎ（Escalate）○引き継ぎ先は Teams Phone、メール、Customer Engagement（会話をまるごと渡し、空いている担当者を探す）の3種類。Teams Phone では外部の電話番号への直接転送も可能。[9][21]
声による本人確認△話しているあいだに声紋で本人を確かめる機能。Dynamics 365 アプリが有効な環境が必要で、方針は CCI ポータルで管理。生体情報の扱いは各国の法令に沿う責任が利用者側にあります。[12][27]
前回の会話を覚える（メモリ）△名前・未解決の用件・前回の要約を次の会話で使えます。独自の項目も5つまで。電話⇔チャットをまたぐには、共通の顧客IDの設定が必要です。[14]
音声の細かい調整○声の種類・話す速さ、プッシュボタン入力（DTMF）、聞き取り感度、無音時の対応、処理待ちの「少々お待ちください」メッセージなど。[11]
多言語○主言語＋追加言語を設定。リアルタイム音声モデル（GPT Realtime）は会話の途中で言語を自動で切り替えます。翻訳ファイルの書き出し・取り込みも可能。[13]
日本語―Copilot Studio 全体の対応言語には日本語があります。ただ、このハーネスで日本語の音声・チャットが使えるかを明記したページは見つかりませんでした。[25][13]
公開と運用
公開先（単独）○デモ用Webサイト（公開すると自動で作られる）、自社サイトへのWebチャット埋め込み、Teams Phone の電話番号。[20][19]
既存のコンタクトセンターにつなぐ△Dynamics 365 Contact Center、Genesys、その他（持ち込み）。Cisco・Avaya・Five9 とは CCI 側で連携。コンタクトセンターへの接続は CCI ポータルからのみで、担当の管理者が行います。[20][4][33]
テスト・評価・監視○Webチャットと音声通話での試し打ち、テスト問題集での一括評価、公開後の解決率・引き継ぎ率・満足度・消費クレジットの確認。[17][18][22]
管理者からの見える化○作った時点で Microsoft Agent 365 の一覧に載り、持ち主・チャネル・使っている道具や権限を管理者が確認できます。[29][33]
日本のリージョンで使う✕対応地域はアジア（香港）、オーストラリア、カナダ、ヨーロッパ、スイス、UAE、イギリス、アメリカのみ。公式に「ここに挙げた地域だけで使える」と書かれており、日本は入っていません（2026-11-24 時点）。[23]
専門係ごとに別のAIモデル―「近日対応」と予告されている段階。今はモデルのモード（コスト重視／速さ重視）を受付役で選び、全員に共通で効きます。[33][16]

実際の画面：作ってから公開するまで

この見取り図について：Microsoft Learn の手順説明に出てくるタブ名・ボタン名・項目名をもとに、画面の構成を再現したものです。実際の色・配置・細部とは異なります。公式のスクリーンショットは、発表ブログ[29]に掲載されています（著作権に配慮し、このページには転載していません）。ボタン名は英語画面の表記です。

画面に入るまで

  1. 入口は2か所
    ホーム画面の「Other ways to build」にある「Customer conversation agent」タイル、またはエージェント一覧の「New agent」から「Customer Conversation」バッジ付きの「Agent」を選びます[4]。
  2. やりたいことを文章で説明する
    窓口の内容を書くと、名前・説明・指示・チャネル・ナレッジ・ツールの案を自動で作ってくれます。何度かやりとりして練り直すことも、「Start from scratch」で白紙から作ることもできます[4]。
  3. CCI ポータルからも同じものが作れる
    コンタクトセンターにつなぐ予定なら、CCI ポータルの「Customer Assist Agent」から作っても、中身の編集画面は同じです[26]。

活用事例

一般提供から1週間ほどなので、公開されている導入事例はまだ少数です。「実際の導入例」「パートナーの声」「公式が挙げる想定シーン」「日本での使いどころ（筆者の考察）」を分けて載せます。

実際の導入例（公式ブログ掲載） 米国の大学・医療機関：人事サービスデスクの問い合わせ窓口

Thomas Jefferson University が、人事サービスデスクに専門AIエージェントを導入。福利厚生への加入、対象かどうか、補償内容、請求などの質問に答える用途です。9月にプレビューで試し始め、6週間後には本番稼働の準備に入ったと、同大学の最高デジタル・情報責任者がコメントしています。

公式が挙げる想定シーン 請求トラブルで社内の返金ルールを参照

請求に関する苦情の対応中に、SharePoint にある返金ポリシーや、Teams で合意された例外対応を参照して答えます（Work IQ＝Microsoft 365 の社内情報を使う仕組み）。

出典：[29][33]
公式が挙げる想定シーン 銀行：残高確認係とカード支払い係の連携

「同じ銀行の口座からカード代金を払いたい」と言われたら、受付役が残高確認係に残高を確かめさせ、続いてカード係に支払いをさせる、という係どうしの連携を指示で書けます。

出典：[6][29]
公式が挙げる想定シーン 再来店のお客さまを覚えている花屋の窓口

メモリを使い、前回の未解決の用件があれば「おかえりなさい、前回の○○の件から進めますか？」とあいさつを変える指示例が紹介されています。

出典：[14]（架空の会社 Contoso Flowers の例）
日本での使いどころ（筆者の考察・推測） 代表電話・予約受付・社内ヘルプデスク

公式の例から考えると、企業や自治体の代表電話の一次受付、予約・変更の受付、Jefferson の例のような人事・ITの社内ヘルプデスクが向いていそうです。ただし下の「日本での注意」のとおり、地域と日本語の確認が先です。

公式の事例ではありません。

2026年11月25日時点で、日本企業の導入事例は見つかりませんでした。また、海外メディアは Ignite で航空会社などの事例も報じていますが、記事本文を確認できなかったため載せていません。

料金：使った分だけ Copilot クレジット

従量課金で、作っている途中から消費しますこのハーネスは Copilot クレジット（Copilot Studio の利用量を数える単位）の従量課金です。公開後だけでなく、作成・テスト・評価でもクレジットを使うことがあります[3][24]。
会話の重さと「声の種類」で消費量が変わります消費量は、会話の複雑さ（軽い・中くらい・重い）と、やりとりの形（チャット、生成AI音声、プレミアム音声）の組み合わせで変わると説明されています。具体的な目安は公式ページの図と、Copilot Credits 見積もりツールで確認します[24]。
使った量は Monitor と管理センターで見られますエージェントごとの消費は Monitor タブの Billing、環境やテナント全体は Power Platform 管理センターの「Licensing」→「Copilot Studio」で確認します[24][22]。
別の費用がかかる場合もTeams Phone で使うには Copilot Studio のテナント・ユーザーライセンスと Teams Phone のライセンスが必要です。また、他社のコンタクトセンター製品につなぐ場合、その会社のAPI利用料などは CCI の料金に含まれません[19][32]。

日本で使うときの注意点

説明のときに外すと話がずれる前提条件です。提供状況は段階的に広がるので、テナントや時期によって変わる前提で確認してください。

1. 日本リージョンの環境では、今は使えない前提で対応地域（Dataverse のリージョン）は、アジア（香港）・オーストラリア・カナダ・ヨーロッパ・スイス・UAE・イギリス・アメリカです。公式に「Copilot Studio 自体はほかの地域でも使えるが、このハーネスはここに挙げた地域だけ」と書かれています（11/24更新）[23]。データを国内に置く必要がある案件では、今の時点では選べません。
2. 日本語の対応は要確認Copilot Studio 全体では日本語に対応していますが、このハーネスでの日本語の音声・チャットを明記したページは見つかりませんでした[25][13]。音声で使うなら、声の種類（日本語の声があるか）も実機で確かめてください。
3. 電話ではサインインできない本人の権限で見る資料（SharePoint など）は、チャットでしか使えません。電話で本人確認が必要なら、声の本人確認（Dynamics 365 アプリが有効な環境が必要）や、SMS のワンタイムパスコードを使います[10][12][15]。
4. 声の本人確認は、法令対応が前提声紋は生体情報です。公式も、各国の法令（米イリノイ州の生体情報保護法や EU の GDPR などを例示）に沿って、通知や同意を取る責任は利用者側にあると明記しています[27]。日本では個人情報保護法との整理が必要になります。
5. 無音検知は最初はオフ何もしないと、お客さまが黙ったときにエージェントがずっと待ち続けます。無音検知（既定7秒）と、そのときの動き（聞き直す・切る・人に回す）を必ず決めておくよう公式が注意しています[11]。
6. コンタクトセンター接続は CCI ポータルからCopilot Studio から作り始めてもよいですが、既存のコンタクトセンターへの接続や生体認証・品質管理の設定は CCI ポータル側で行います[4][26]。
7. AIモデルは2つのモードから「Auto — optimized for cost（チャット向け）」と「Auto — optimized for latency（音声向け）」があり、受付役で選ぶと専門係にも効きます。アジア地域では、リアルタイム音声モデル（gpt-realtime-2.1）が「地域をまたいだ処理（cross-geo）」と表に書かれています[16]。
