AI活用事例Copilot Studio2026年11月5日／金融（Rabobank）・カスタマーサポート

銀行のチャットが、問い合わせの6割以上を人に回さず解決できるようになりました

オランダの銀行 Rabobank は、電話とチャットの問い合わせが増える中で、外部ベンダー頼みの古いチャットボットの更新に時間がかかっていました。

そこで Copilot Studio（会話で答える AI エージェントを、専用の画面で作れる Microsoft のツール） に移行し、顧客向けのエージェントを3つ（電話1つ、チャット2つ）作りました。

いまは1日あたり電話2万件・チャット7,000件を扱い、チャットの62%を担当者に回さず解決できています（Rabobank が公表した数字です）。

01こんな場面、ありませんか

お客様から「カードを止めたい」「口座の件で聞きたい」といった問い合わせが毎日たくさん届きます。チャットの答えを直したくても、更新のたびに専門の開発者を待つことになった経験はありませんか。

Rabobank の旧システムでは、チャット用と電話用で同じ内容を別々に更新する必要があり、外部のシステムとつなぐのも大変でした。担当者は「ひとつの会話基盤で全部を管理し、自分たちで改善したい」と考えていました。

02やってみたこと

Copilot Studio（会話で答える AI エージェントを、専用の画面で作れる Microsoft のツール）で、質問の意図を読み取って、手続きごとの会話の流れ（トピック）に案内する仕組みを作りました。

電話では、まず用件を聞いて適切な担当者の列につなぎます。チャットでは、カードの停止のような手続きを最後まで案内します。人に引き継ぐ部分には Genesys Cloud（コールセンター用のシステム）を使い、Copilot Studio との間をつなぐ中継プログラムを自作しました。

  1. 旧システムの会話の内容（トピック）を Copilot Studio に移しました。チャット用のエージェントは3か月で作って公開しました。
  2. 質問の意図を見分けるために、「こう聞かれたらこの流れ」という言い回しの例（トリガーフレーズ）を整え、外部の意図の一覧とも組み合わせました。
  3. Power Automate（作業を自動でつなぐ Microsoft のツール）で、銀行内の仕組みと連携しました。
  4. 答えられない質問には、生成 AI を使う予備の流れ（フォールバック）を用意しました。Rabobank は規制に合わせて、この部分を Copilot Studio の外の自社の Azure 環境に置いています。
  5. 会話の記録を Power BI（数字をグラフにする Microsoft のツール）で分析し、個人が分からないようにした実際の質問でテストしてから本番に反映しました。

※ 手順の並びは、出典の説明を読みやすく整理したものです。画面の操作や設定値までは公表されていません。

03どう変わったか

これまで

チャットと電話を別々に更新する必要があり、変更には専門の開発者と外部ベンダーが必要でした。外部システムとのつなぎ込みも難しい状態でした。

いま

1つのプラットフォームで電話・チャットのエージェントを管理でき、外部の助けなしに自分たちで更新できます。チャットの62%は担当者に回さずに解決しています。

1日2万件の電話と7,000件のチャット、チャットの自己解決率62%は、いずれも Rabobank が公表した数字です。それ以外の効果（時間やコストの削減など）は公表されていません。

04明日から試すには

  1. 自分の部署に来る問い合わせを1か月分ふり返り、同じ質問が多い順に3つ書き出します。
  2. その3つについて、正しい答えと「こう聞かれたらこう案内する」という言い回しの例を集めます。
  3. Copilot Studio で小さなエージェントを1つ作り、実際の質問で試して、答えられなかったものを記録します。

準備物は、問い合わせの履歴と、正しい答えがまとまった資料です。Copilot Studio の利用にはライセンスや管理者の設定が必要で、組織の契約によって使える機能が変わります。

05つまずきやすいところ

生成 AI の機能は、規制と品質の確認に時間がかかりました

Rabobank は、規制への対応や品質の確認が難しいことを理由に、Copilot Studio に組み込まれた生成 AI の機能をまだ使っていません。サイトの8,000件以上のページを知識源にする難しさもあり、自社の Azure 環境で別の仕組みを作りました。また、意図の読み取りがうまくいかないと、電話が違う担当者につながってしまうと説明しています。

お客様の会話を使ってテストするときは、個人が特定されないように加工することが前提です。AI が間違った案内をする可能性もあるので、お金や契約に関わる内容は、必ず担当者に引き継げる出口を用意しておきましょう。

06おわりに

この事例の要点は、AI の賢さよりも「意図を読み取り、テストし、改善し続ける仕組み」を先に整えたことです。出典も、意図の読み取りを改善する流れと、実際の質問を使ったテストを大事な学びとして挙げています。

自分の職場に置き換えると、社内のヘルプデスクや総務への問い合わせにも使えます。「よくある質問の上位10件」を集めて、答えの案内と「人につなぐ条件」を決めるところから始めると、小さく試せます。
