Copilot の「プラグイン」と「プロジェクト」
それぞれ何をする機能？

2026年秋、Microsoft 365 Copilot（Microsoft Copilot アプリ）に「プラグイン」と「プロジェクト」という2つの機能が加わりました。どちらも新しい機能ですが、役割はまったく別物です。この記事では、それぞれの中身・使い方・提供時期・管理者が設定する場所を、公式ドキュメントをもとにかんたんに整理します。

調査日
2026-11-24
対象
Microsoft 365 Copilot（一般の商用テナント向け）
根拠
Microsoft Learn・メッセージセンター・Microsoft 公式ブログ 10件

結論

プラグインは Copilot に「できること」を足す道具箱、プロジェクトは自分の仕事を案件ごとにまとめるフォルダです。

  1. プラグインは、作業の手順書（スキル）・外部サービスとの接続（コネクタ）・エージェントを1つにまとめたパッケージです。Chat・Cowork・Word・Excel・PowerPoint・SharePoint などで同じ仕組みが使われます[1][3]。画面の「Agents」ボタンは、11月下旬までに「Plugins」に置き換わります[4]。
  2. プロジェクトは、ひとつの仕事に関係するチャット・Cowork のタスク・ファイル・指示をひとまとめにする場所です。回答はまずプロジェクトの中身をもとに作られます[9][10]。使えるのは作った本人だけです。チームで共有する場所としては、別に「ワークスペース」があります[8][10]。
  3. 管理者は、プラグインを Microsoft 365 管理センターの「Agents > Tools」で許可・ブロック・配布します[2][6]。プロジェクトは管理者が有効にする操作は要りません。ただし Cowork を使えるかどうかは、支出ポリシー（従量課金の設定）で決まります[9][10]。

先に押さえておきたい言葉

スキル
「この仕事はこの手順で、この品質で進める」をまとめた手順書のようなものです。中身は SKILL.md というテキストファイルです[1]。
コネクタ
Copilot が社内外のサービス（Salesforce や Slack など）のデータを読んだり、操作したりするための接続口です[3]。
MCP サーバー
AI と外部サービスをつなぐ共通ルール（Model Context Protocol）に沿った窓口です。コネクタの仲間と考えて大丈夫です[1][4]。
Cowork
Microsoft 365 Copilot の中で、手順の多い仕事を段取りして進めてくれる機能です。従量課金（使った分だけ請求される仕組み）の設定が前提です[10]。
Frontier
Microsoft の新機能を先に試せるプログラムです。一般提供より早く機能が届きます。
Standard／Deferred
Copilot アプリの更新を受け取るタイミングの設定です。Deferred（遅延）の組織には、新機能が少し遅れて届きます[10]。

プラグインってなに？

Copilot に、あとから専門の手順や外部サービスとの接続を足すためのパッケージです。スマホにアプリを入れる感覚に近いです。Microsoft は「Microsoft 365 Copilot などに新しい能力を足す、インストールできるパッケージ」と説明しています[1]。

どこで使える？

Copilot アプリの Home（Chat・Cowork）、Code、Autopilot、Word・Excel・PowerPoint、SharePoint で、同じ「プラグイン」の仕組みが使われます。今後は Copilot Studio・GitHub Copilot・Microsoft Foundry にも広げる予定です[3][4]。PowerPoint の Copilot では、11月中旬から Frontier 向け、11月下旬から一般向けに展開が始まり、11月末までに完了する予定です[7]。

どんなプラグインがある？

Microsoft 製（業務別）

法務・営業・財務・サービス・資本市場・教育などの業務向けです。会計（Accounting）は Frontier 向けです[5]。

Microsoft 製（製品連携）

Dynamics 365 の Sales・Customer Service・ERP、Planner、Viva Engage、Fabric IQ などです。Dynamics 365 の Sales と Customer Service は最初からオンになっています[5]。

パートナー製

Asana・Box・Canva・Notion・Slack・Salesforce・GitHub などです。Microsoft によると、100以上がすでに提供されています[3][5]。

自社製

自分たちで作ったパッケージ（.zip）をアップロードして使えます。組織全体に共有するには、管理者の承認が必要です[6]。

使う人から見ると（Cowork の場合）

  1. 探して追加する

    Cowork の左メニューにある「Plugins」から探して追加します。パートナー製のプラグインは、管理者が使える状態にしてからでないと追加できません[5]。

  2. 会社が配ったものは最初から入っている

    管理者が配ったプラグインは「Added Plugins」に自動で並び、「Managed by your organization」と表示されます。自分では削除できませんが、「Sources & Skills」パネルで自分の会話でのオン・オフは切り替えられます[6]。

  3. 外部サービスには自分でサインインする

    コネクタを使うには、一人ひとりがサインインや同意をします。管理者が代わりにサインインすることはできません[6]。

ボタンの名前が変わります

「Agents」「Agents & Skills」「Customize」のボタンは、11月下旬までに「Plugins」に置き換わります。管理者側の作業は不要ですが、社内マニュアルや研修資料に古い名前が書いてあれば、書き換えが必要です[4]。

プロジェクトってなに？

ひとつの仕事に関係するチャット・Cowork のタスク・ファイル・指示・成果物を、まとめて置いておく場所です[9][10]。Microsoft は「一度コンテキストを入れておけば、プロジェクトの中のチャットやタスクはそれを前提に動く」と説明しています。毎回「この案件はね…」と説明し直さなくて済むのが、いちばんの良さです。

ここがポイント

  • 回答のもとになる情報まずプロジェクトの中身、次にふだんの Microsoft 365 の仕事の情報をもとに答えます[9][10]。
  • ファイルの置き場所プロジェクト自体は中身を保存しません。ファイルは OneDrive に置かれ、今の権限・秘密度ラベル・保持ポリシーがそのまま効きます。Copilot が作った Word・Excel・PowerPoint も本人の OneDrive に保存されます[9]。
  • 共有はできないプロジェクトは作った本人だけのものです[8]。チームで同じ情報を使いたいときは「ワークスペース」（旧ノートブック）を使います[10]。
  • あとから整理できる既存のチャットやタスクを追加したり、ドラッグで移動したりできます。タスクをプロジェクトから外しても会話は消えません。アーカイブと復元、名前や色の変更もできます[8]。

管理者が設定するところ

プラグインは管理センターで管理します。プロジェクトには専用の設定はありません。

  1. 1

    どんなプラグインがあるか見る

    Microsoft 365 管理センター›Agents›Tools›Registry

    Microsoft 製・パートナー製・自社製のプラグインと、中に入っているスキル・コネクタを確認できます[1][2]。

  2. 2

    使える人を決める

    Agents›Tools›Plugins›（プラグイン名）›Users

    「全員」「特定のユーザー・グループ」「ブロック」から選びます[2][6]。

  3. 3

    最初から入れておく（必要なら）

    「Installed for」で全員か特定のグループに配ると、利用者の画面に自動で追加されます。利用者は削除できません[6]。

  4. 4

    Cowork を使える人を確認する

    プロジェクトには設定は要りません。ただ、Cowork を使えるのは支出ポリシーの対象の人だけなので、対象者と従量課金の設定が意図どおりか確認しておきます[10]。

画面名は英語版の公式ドキュメントの表記です。日本語表示での名前は今回確認していません。

説明するときの注意点

  • 届く時期は組織によって違うFrontier／Standard／Deferred の設定やテナントによって、届く時期や見え方が変わります。プロジェクトの入口も「Cowork タブから」と「Home のメニューから」の2通りの説明があり、時期によって違う可能性があります[8][10]。
  • 他社製プラグインはデータの行き先を確認するパートナー製のプラグインは外部のサービスとつながります。承認する前に、発行元・必要な権限と同意・つながる外部サービスを確認するよう、Microsoft の管理者ガイドに書かれています[2]。
  • ブロックしても全部は止まらないことがあるあるプラグインをブロックしても、ほかのプラグインと共有している MCP サーバーやコネクタは使える場合があります。また、ブロックは新しい会話から効きます[2][6]。
  • 情報バリアを使っている組織プラグインの管理は、情報バリア（部署間の情報のやりとりを制限する仕組み）に対応していません[6]。
  • 日本語対応プロジェクトは「tier 1 の言語」で提供とされていますが、どの言語が含まれるかは今回確認していません未確認[9]。
