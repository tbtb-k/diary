Overview

全体像：Copilotは「仕事のOS」へ

基調講演でサティア・ナデラCEOは、Copilotを「仕事の新しいOS」と呼びました。仕事をするときの土台そのものをCopilotにする、という意味です。講演の冒頭では、先週のOutlook（Microsoft 365）の大規模障害にも触れ、「やるべきことがある」と述べています。発表は次の4層で見ると整理しやすいです。

使う画面：Copilotアプリの「Home」入口は1つ。Autoが仕事に合うモデルや深さを選ぶ

Chatすぐ聞く・調べるGA（Home）
Cowork手順のある仕事を任せる提供中・従量課金
Code言葉でアプリや道具を作るFrontier・12月GA予定
Autopilotずっと動き続けて任せるFrontier・当初米国

裏で支える文脈：Microsoft IQGA。新しい購入単位は不要

Work IQ（M365の仕事の文脈）Fabric IQ（業務データ）Foundry IQ（AI開発の知識）Web IQ（Web検索）

作る場所

Copilot Studio と Copilot Managed Runtime。エージェントもアプリも作り、テナントの中で動かす。

管理する場所

Agent 365。エージェントのID・権限・セキュリティ・費用をまとめて管理する。

状態ラベルの読み方

  • GA一般提供。正式なサービスとして使えます（地域や一部の機能に限られることもあります）。
  • 展開中順番に配られている途中で、届く時期はテナントごとに違います。
  • プレビューお試し版です。「Frontier」は新機能を先に試せる早期アクセスの仕組みで、参加している組織だけが使えます。
  • 予定提供時期が発表されたもので、まだ使えません。

2026/11/17GA（一般提供）MC1535647

「Home」と「Office in Copilot」が一般提供に

何があった？
Homeは、ChatとCoworkを1つにまとめた新しい入口です。「Auto」が依頼に合うモデルや考える深さを選び、複雑な依頼ではCoworkへの切りかえをすすめます。Office in Copilotは、Copilotアプリの中でWord・Excel・PowerPointを作成・共同編集できる機能です。
嬉しい・注意点
作ったファイルはOneDriveに保存され、権限や秘密度ラベルがそのまま効きます。Copilotのライセンスに含まれ、追加の従量課金はありません。Deferred（新機能を遅らせて受け取る設定）の組織には、Homeは11月下旬から届きます。
支援現場でのひとこと
勉強会の画面キャプチャはHome前提に差しかえましょう。「まずChat、手順の多い仕事はCoworkへ」と説明すると伝わりやすいです。

出典：Microsoft Copilot Blog（2026/11/17）／Book of News／MC1535647

2026/11/17プライベートプレビュー（Frontier）

1日の優先順位を整理してくれる「Today」

何があった？
メール・予定表・Teams・会議・タスクを横断して、「見逃したこと」「対応が必要なこと」「後回しでよいこと」を整理し、対応の下書きまで用意する画面です。CopilotアプリとOutlookに入ります。
嬉しい・注意点
朝のまとめ「Today Brief」はM365 Copilotのライセンスに含まれます。1日を通して更新し続ける「Today Feed」には、Copilot Credits（使った分だけ払う従量課金）が必要です。

出典：Microsoft Copilot Blog（2026/11/17）／Book of News

Notebooksが「Workspaces」に。人とエージェントの共有スペース

何があった？
Copilot Notebooksの発展形で、チームのメンバー・資料・エージェントを1か所に集めて一緒に作業する場所です。Teamsからも続きができ、既存のノートブックは中身を保ったまま移ります。
嬉しい・注意点
Standardリリースには2027年1月まで、Deferredには2月までに届く予定です。使える機能はライセンスによって変わります。

2026/11/17Frontier（GAは12月予定）MC1519871

話すだけでアプリを作る「Copilot Code」、スマホとMacにも

何があった？
作りたいアプリやダッシュボードを言葉で説明すると、Copilotが作ってくれる機能です。作ったアプリはWord文書のように共有できます。今回、iOS・Android・Macにも広がり、Windowsでは許可したファイルと通信だけに触れる「ローカルSandbox」も使えるようになりました。
嬉しい・注意点
一般提供はBook of Newsでは12月、Copilot Blogでは「数週間以内」。Copilot Creditsの従量課金で、管理者が支出ポリシー（だれがいくらまで使えるかの決まり）にCodeを含める必要があります。
支援現場でのひとこと
「Power Appsとの使い分けは？」と聞かれそうです。まずは個人やチームの小さな道具づくりから試すのがおすすめです。

2026/11/17Frontierで段階展開（当初は米国のみ）MC1557730

指示を待たずに動き続ける個人用エージェント「Autopilot」

何があった？
任された目標を、1回ずつの指示を待たずに進め続ける常時稼働のエージェントです。自分専用のIDやメールボックス、リモートのコンピューターを持ち、TeamsやOutlookで@メンションして仕事を頼めます。持ち主が決まっていて、操作は記録され、大事な操作の前に確認を求めることもできます。
嬉しい・注意点
既定ではオフで、管理者の有効化と、持ち主のM365 Copilotライセンス・従量課金が必要です。当初は対象の米国顧客のみで、一般提供の時期は未定です。
支援現場でのひとこと
日本ではまだ使えませんが、「AIにIDを持たせて仕事を任せる」流れは今回の発表全体に共通します。ID・権限・費用の決め方を、情報システム部門と早めに話しておきましょう。

Copilot Studio・エージェントづくり

4件
2026/11/17GA（一般提供）

エージェントの新しい実行の仕組み「Microsoft Copilot harness」

何があった？
ハーネスは、AIモデルにツールやファイルを使わせて仕事を進めさせる「段取り役」の仕組みです。Microsoftの社内評価では、従来のStandardハーネスに比べて、ナレッジ回答の品質が20ポイント超上がり、複数ツールを使う課題の成功率は87.0%→98.9%、AIが読む文字量（入力トークン）は45%減ったとしています。
嬉しい・注意点
数字はMicrosoft自身の評価で、どのエージェントでも同じ効果が出るとは限りません。
支援現場でのひとこと
資料を分析するエージェントや、複数のツールを組み合わせるエージェントは、新しいハーネスで作って比べる価値があります。Creditsの消費もあわせて確認しましょう。

出典：Microsoft Dynamics 365 Blog（2026/11/17）

2026/11/17GA（一般提供）

Copilot Studioで「アプリ」も作れるように。基盤はCopilot Managed Runtime

何があった？
作ったアプリは、テナント（自社のM365環境）の中で動く実行基盤「Copilot Managed Runtime」（こちらもGA）の上で動き、IDや廃止までの管理もテナント内で行います。Copilot Studioの画面のほか、CoworkやCodeへの言葉での依頼、CLI（コマンドで操作する道具）からも作れます。エージェントやワークフローを手元で作ってCLIで公開し、GitHubで版を管理する作り方にも対応します。
支援現場でのひとこと
「Copilot Studio＝エージェントを作る場所」という説明は、「エージェントもアプリも作り、社内で安全に動かす場所」へ更新しておきましょう。

出典：Microsoft Dynamics 365 Blog（2026/11/17）／Book of News

2026/11/1712月にパブリックプレビュー予定

エージェントが自分のアカウントを持つ「Agent Accounts」

何があった？
Copilot Studioのエージェントが自分のアカウントを持ち、文書・メール・Teamsを通じて仕事を任せられるようになります。記憶（memory）と、何かをきっかけに自動で動く「トリガー」もあわせて案内されました。エージェントはM365の仕事の文脈（Work IQ）ともつながります。
支援現場でのひとこと
「作った人が異動したらエージェントが止まった」という相談への根本的な答えになりそうです。12月のプレビューで管理側の設定を確かめましょう。

出典：Microsoft Dynamics 365 Blog（2026/11/17）

何があった？
エージェントがクラウド上のWindows PCを使い、人と同じように画面を操作する仕組みです。Copilot StudioではStandardハーネスの「コンピューター操作ツール」として使え、Microsoft Copilot harnessでは12月にプレビューになります。費用はCopilot Creditsでまとめて払えるようになりました。

APIのない古い業務システムを自動化したい、という相談のときの選択肢になります。

Copilotの「社内の文脈」を外からも使える「Microsoft IQ」

何があった？
Copilotの裏で「この仕事に何が関係あるか」を集めている仕組みを、まとめて使えるようにしたものです。Work IQ・Fabric IQ・Foundry IQ・Web IQの4つで構成され、GitHub CopilotやFoundry、MCP（AIが外部とつながる共通規格）に対応したエージェントからも使えます。新しい購入単位（SKU）は不要です。
嬉しい・注意点
新着メッセージなどに反応してエージェントが動くWork IQの「Listen」はプレビュー、OpenAIやAnthropicの基盤との連携は「近日」です。ナデラCEOは「数百の新しいコネクタ」も発表しました。
支援現場でのひとこと
「Copilotは社内のことをどこまで知っているの？」の答えがWork IQです。権限のないファイルは見えない、という基本とセットで説明しましょう。

エージェントの管制塔「Agent 365」が他社のエージェントにも拡大

何があった？
Agent 365は、組織のエージェントのID・権限・セキュリティをまとめて管理する仕組みで、5,000万を超えるエージェントが登録されています。今回、Anthropic・Databricks・OpenAI・Salesforceの基盤のエージェントや、複数テナントの管理にも広がりました。
嬉しい・注意点
  • Microsoft製や、Microsoftの基盤で作ったエージェントの管理情報は、Agent 365のライセンスなしで見られます（GA）。
  • 動作中のエージェントの危険度を判定する「Dynamic Agent Risk」はプレビュー、持ち主不在のエージェントを見つける「Action center」は12月にプライベートプレビュー予定です。
  • すべての機能には、Agent 365またはMicrosoft 365 E7のライセンスが必要です。
支援現場でのひとこと
「だれが作ったかわからないエージェントが増えて不安」という声への答えです。まずはライセンスなしで見られる範囲で棚卸しから始めましょう。

日本の現場で紹介するときの注意点

発表をそのまま「もう使えます」と伝えると、話がずれやすいポイントです。

  1. 日本語・日本での提供時期は、今回の公式発表には書かれていません。Autopilotのように「当初は米国のみ」と明記されたものもあります。
  2. Frontierの機能は、参加している組織でしか試せません。Workspaces、Code、Autopilot、Today、Business Analyticsなどです。
  3. 従量課金（Copilot Credits）が前提の機能が増えています。Cowork、Code、Autopilot、Today Feedなどは、管理者が支出ポリシーを決めてから使う形です。
  4. 「GA」でも地域や一部の機能に限られることがあります。Book of Newsは会期中に更新されるので、紹介前に最新の内容を確かめましょう。

かみ砕き用語

Entra Agent ID（エージェントID）

エントラ・エージェント・アイディー。Autopilot、Agent Accounts、Agent 365に共通する言葉です

ひとことで

AIエージェントに1つずつ配る「社員証」です。人のアカウントを管理するMicrosoft Entra IDの中に、エージェント用として作られます。

たとえるなら

派遣スタッフに渡す入館証です。だれの指示で働いているか（持ち主）、どの部屋に入れるか（権限）、いつ何をしたか（記録）が、入館証ごとにわかります。

押さえておきたいこと

  • Autopilotは1体ごとにEntra Agent IDと持ち主を持ち、IT部門が範囲を絞ったり止めたりできます。
  • 人のアカウントを借りて動かすより、権限を必要な分だけに絞りやすく、作った人が異動しても止まりにくくなります。
勉強会での言い方：「これからのエージェントは、1体ずつ社員証を持って働きます。だから、だれの部下で、どこまで入れて、何をしたかを、人と同じように管理できるんです。」
