AI活用事例Copilot Studio2026年10月7日／飲料製造・販売（Coca-Cola Andina）・人事問い合わせ対応

300人以上の社員が使う人事アシスタント「Andi」を、Copilot Studio で作りました（Coca-Cola Andina）

南米の大手ボトラー（飲料の製造・販売会社）Coca-Cola Andina では、人事チームが日々の定型的な質問に追われていました。現場の社員は、国や拠点ごとに違う人事ルールを調べる手間もかかっていました。

そこで Copilot Studio（Microsoft の、AI エージェントをほぼノーコードで作るツール）を使い、人事アシスタント「Andi」を作りました。社員は WhatsApp や Teams から質問できます。

現在はアルゼンチンの4地域で300人以上が使っています。人事チームは、定型的な質問に使う時間が大きく減ったと公表されています。

01こんな場面、ありませんか

「有給は何日残っているのか」「この手当は自分の契約でも出るのか」といった質問を、そのたびに人事へ聞くことはありませんか。答えが規程のどこにあるのか、探すだけで時間がかかります。

Coca-Cola Andina は、アルゼンチン・チリ・ブラジル・パラグアイで事業をしています。制度は国、地域、契約の種類によって変わります。人事チームは同じような質問に追われ、遠くの工場で働く社員は、必要な情報にすぐ届きませんでした。

02やってみたこと

Copilot Studio は、AI エージェント（質問に答えたり、作業を代わりにしたりする AI）を作るツールです。Andi は、社員が会社のアカウントでサインインすると、勤務地や役職などの情報を踏まえて答えます。

回答のもとになるのは、SharePoint（社内の共有ファイル置き場）に置いた人事の資料です。資料はアップロードするだけで使えて、ベクトルデータベース（AI 用の検索の仕組み）などは要らなかったと、開発者は話しています。人事の専門家の見方に合わせるため、指示文を何百回も直したそうです。

  1. IT 担当者と人事担当者が一緒のチームを作ります。
  2. 人事の資料を SharePoint にまとめ、Copilot Studio に取り込みます。
  3. Entra ID（Microsoft の社内アカウント管理）でサインインさせ、社員の勤務地や役職に合った答えを返します。
  4. Power Automate（作業の自動化ツール）と Power Apps で、人事担当者へのチケットを作れるようにします。
  5. Direct Line API という仕組みで、WhatsApp にも公開します。

※ 手順1〜2の順序は、記事の内容から一般的な作り方として整理したものです。Coca-Cola Andina が実際に踏んだ順序や期間は公開されていません。

03どう変わったか

これまで

人事チームが定型的な質問に何度も答えていました。遠くの工場の社員は、自分に当てはまる情報をすぐに得られませんでした。

いま

社員が WhatsApp や Teams で Andi に質問し、自分の条件に合った答えを受け取れます。人事は複雑な相談に集中できます。

Coca-Cola Andina が公表した数字は、アルゼンチンの4地域で300人以上が使っているという点です。削減時間や満足度などの数字は公表されていません。今後はアルゼンチン全体、ほかの国へ広げ、Teams や Azure AI Document Intelligence（文書の読み取りサービス）との連携も予定されています。

04明日から試すには

  1. 人事や総務に寄せられる質問を、よく来る順に10個ほど書き出します。
  2. その答えが載っている規程や FAQ を、1か所のフォルダにまとめます。
  3. Copilot Studio で小さな試作を作り、チームの数人に使ってもらいます。

準備物は、整理した資料と、試してくれる数人です。Copilot Studio が使えるかどうかは、ライセンスや社内の設定で変わります。まずは情報システム部門に確認してください。

05つまずきやすいところ

国・地域・契約で制度が違う

記事でも、人事制度が国や拠点、契約の種類で違うことが課題として挙げられています。そのため、サインイン情報を使って答えを出し分ける設計になっていました。

真似をするときは、見せてよい資料の範囲と、閲覧権限を先に決めてください。AI は、もっともらしい間違いを答えること（ハルシネーション）があります。重要な内容は、人事担当者に確認できる経路を残しましょう。

06おわりに

Andi の工夫は、答えるだけでなく、必要なときに人へつなぐところまでを一つの流れにしたことです。この形は人事に限らず、問い合わせを受ける部署なら応用できます。

自分の職場に置き換えると、経理の立替精算、情報システムのパスワード再発行、総務の備品申請など、「規程を見れば答えられる質問」が多い窓口から試せます。
