Copilot Cowork と Copilot Code、何が違う？

どちらも Microsoft Copilot アプリの中にあるタブですが、得意なことははっきり分かれています。Microsoft の公式ドキュメントで確かめた内容を、星取表（○×で見比べる表）にまとめました。

調査日
2026-11-17
対象
Microsoft 365 の職場アカウントで使う Copilot Cowork と Copilot Code

ひとことで言うと

Cowork は「仕事を代わりに片付けてくれる秘書」、Code は「何度も使える道具（アプリ）を作ってくれる工作室」です。

アプリ、ダッシュボード、社内ツール、簡単な Web サイト、自動化の仕組み[5]
しくみ
中身はプログラマー向けの GitHub Copilot と同じ技術で、隔離された安全な場所で動きます[11]。コードの知識は要りません[5]。

会話はタブごとに分かれていて、Code での会話は Chat や Cowork のタブには出てきません[5]。

見分けるコツ

欲しいのが「今回の仕事の完成品」なら Cowork、「これから何度も使う道具」なら Code。

公式も「Cowork は日常業務をこなす」「Code はソフトウェア作りに集中する」と説明しています[7]。同じ「週次報告」でも、今週分の資料なら Cowork、毎週ひらけば最新の数字が見える画面なら Code です。

色付きの行は、2つの違いがいちばんよく出るところです。

こんなときは、どっち？

  • 来週の定例会議を調整して、参加者に案内メールを送っておいてCowork
  • この売上の Excel から、今月の報告用スライドを作ってCowork
  • 毎朝、未読メールと今日の予定をまとめて教えてCowork
  • チームの案件の進み具合が一覧できるダッシュボードを、みんなで使いたいCode
  • 申請フォームと集計画面がセットになった社内ツールがほしいCode
  • ちょっとした計算ツールを、サッと作りたいどちらでも

    Cowork の App スキルでも軽いアプリは作れます（Frontier 限定）[1]。あとから機能を足していくつもりなら Code が向いています。

実は同じところ

  • 料金のしくみ

    どちらもライセンスに加えて、使った分だけ払う従量課金（Copilot クレジット）の対象です。管理者が「誰がいくらまで使えるか」を決めて、初めて使えます[3][4][9][11]。

  • プラグイン（追加の機能パック）

    Code は Cowork と同じプラグインを使えます[7][10]。

  • 作ったアプリの置き場所

    どちらで作ったアプリも、Microsoft が運用する同じ置き場所「Copilot Managed Runtime」で動きます[12]。

  • 中で考えている AI

    どちらも Anthropic の Claude を含む複数の AI モデルから選べます。おまかせ（Auto）にもできます[2][3][8]。

説明するときに気をつけたいこと

  • !

    Code はまだお試し段階です

    Frontier のプレビューなので、仕様が変わる可能性があります[5][6]。今日から Microsoft Ignite 2026（11/17〜20）が開催中で、続報が出るかもしれません。

  • !

    日本語での使い勝手は、試して確かめるのが安全です

    Cowork は「英語に最適化」[2]。Code は「英語のみ」「全言語対応」と、公式ページごとに記載が食い違っています[6][7]。

  • !

    使えるかどうかは会社の設定しだいです

    どちらも管理者が有効にしないと使えません[4][6]。Code を PC 上で動かす「ローカル」モードは、初期設定では使えない（クラウドのみ）ようになっています[9]。

  • !

    細かい料金は公式ガイドの最新版で

    1回あたりの消費量は、公式の Copilot Credits ガイドと見積もりツールで確認します[4]。
