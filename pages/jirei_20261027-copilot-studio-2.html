AI活用事例Copilot Studio2026年10月27日／金融サービス（Morningstar）・資産運用アドバイザーの調査と面談準備

顧客との面談準備が「数時間」から「数回の指示」へ。Morningstar は Copilot Studio のエージェントで調べものを任せています

投資情報会社の Morningstar では、資産運用のアドバイザーの1日のうち約2〜3割が事務的な作業に使われ、顧客との面談の準備にも1人あたり数時間かかっていました。

同社は自社の調査データを Microsoft 365 Copilot につなぎ、Copilot Studio（AI エージェントを作る Microsoft のツール）で、データを選んで組み合わせるエージェントを作りました。

面談準備は「数回の指示」でできるようになり、10〜15年分の履歴調べも数分で終わった例があります。時間の削減率などは公表されていません。

01こんな場面、ありませんか

顧客との面談の前に、保有資産の状況、市場の動き、調査レポートを、いくつものシステムから集めて回る。画面を行ったり来たりするだけで、準備の時間が過ぎてしまう。そんな経験は、営業や企画の仕事にもあるはずです。

出典によると、アドバイザーの1日の約20〜30%は事務的な作業でした。複数のシステムからデータを引き出す必要があり、記事はこれを「swivel-chair effect（椅子を回して別の画面に向かう手間）」と呼んでいます。面談の準備は、顧客1人あたり「数時間」かかっていました。

02やってみたこと

Microsoft 365 Copilot を入り口にして、Morningstar の調査データを MCP（AI が外部のデータや道具を呼び出すための共通の約束事）のサーバー経由で取り込みました。Copilot Studio で作ったエージェントが、どの道具を呼ぶかを判断し、情報を集めて組み合わせます。

規制のある業界のため、エージェントは承認されたデータだけを使い、決められた手順で動き、後から確かめられる形にしています。さらに、非公開企業のデータ（PitchBook）と組み合わせ、企業が資金調達から上場、上場後の動きまでたどるエージェントも作りました。

  1. アドバイザーが、入り口の Microsoft 365 Copilot で依頼を出します。
  2. Copilot が MCP サーバーを通じて Morningstar のデータを取得します。
  3. Copilot Studio のエージェントが使う道具を選び、複数の情報源から集めて組み合わせます。
  4. 面談用の資料や、ポートフォリオの話題の案ができます。アドバイザーが確認して手直しし、最終判断は人が持ちます。

※ 手順は出典の説明を整理したもので、画面上の操作や設定の細部は公開されていません。

03どう変わったか

これまで

複数のシステムを行き来してデータを集め、顧客1人の面談準備に数時間かけていました。

いま

数回の指示で、面談用の資料やポートフォリオの話題の案ができます。10〜15年分の履歴を調べる作業をエージェントが数分で終えた例も紹介されています。

「約20〜30%」「数時間」「数分」は、Morningstar が公表した説明です。出典の成果欄にも「準備の数時間が数分に」とありますが、削減率のような数字は公表されていません。

同社は社内の学習プログラム（AI Academy）も用意しており、指示の書き方、エージェントの組み合わせ方、安全面の注意を学ぶ場に、数百人の社員が登録しているとのことです。

04明日から試すには

  1. 毎回、複数の資料や画面から情報を集める業務を1つ選びます。
  2. 集める情報の「元の場所」と、そのうち正しいと確認済みのものを書き出します。
  3. Copilot Studio で、確認済みの情報だけを使う小さなエージェントを作り、出力を人が見直す手順で試します。

準備するもの：Copilot Studio を使える権限と、使ってよい社内データの一覧です。MCP でつなぐ部分は IT 部門の協力が要ります。使える機能や料金は、ライセンスや社内の設定で変わります。

05つまずきやすいところ

「正しいデータだけを使う」ことが前提でした

出典は、インターネット上の広い情報は質が低かったり偏っていたりするため、確認済みのデータに基づかせることが大切だと伝えています。規制のある環境では、エージェントが承認されたデータだけを使い、決められた流れで動き、後から確認できる状態にしています。

真似するときは、エージェントが見てよいデータの範囲を先に決めましょう。顧客の個人情報は特に注意が必要です。AI の出力は、そのまま顧客に渡さず、必ず人が確かめてください。

06おわりに

この事例のポイントは、新しい画面を足すのではなく、アドバイザーが普段使う Copilot の中にデータを入れたことです。「人が普段いる場所に、確認済みの情報をつなぐ」という考え方は、どの業務にも応用できます。

自分の職場に置き換えると、営業の訪問前の情報集めや、会議前の資料集めが候補になりそうです。まず「毎回、同じ場所から同じ情報を集めている作業」を探してみてください。
