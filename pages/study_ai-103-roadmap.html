Strategy

最短ルートの作戦は3つだけ

  1. 今日、受験日を4週間後で予約する締め切りを先に決めると迷いが消えます。平日1時間＋週末3〜4時間で、合計およそ45時間の計画です。
  2. 配点の6割を占める2分野に、時間の半分以上を使う「計画・管理」と「生成AI・エージェント実装」だけで出題の55〜65%。残り3分野は浅く広くで間に合います。[1]
  3. 公式の無料練習問題を軸に回し、Learnを「引ける」状態にする本番でもMicrosoft Learnを開けます。ただし時間は増えないので、暗記よりどのページに何があるかを知っておくほうが効きます。[3]

Route

4週間のルート

教材はすべて無料の Microsoft Learn です。公式の講師付きコース（4日間）も同じ4つのラーニングパスを使っています。[4] 時間は、ハンズオンを少しやる前提の目安です。

  1. 0
    予約した日いまここ

    Day 0　受験日を決めて、現在地を知る

    ゴール：締め切りと、自分の「知らない言葉リスト」ができている状態。

    約1時間
  2. 1
    1週目いまここ

    地図を手に入れて、生成AIアプリを作る

    ゴール：「Foundry でモデルを選んで、デプロイして、アプリから呼ぶ」流れを説明できる。

    約12時間計画・管理生成AI・エージェント
  3. 2
    2週目いまここ

    エージェントを作り、守り、見張る

    ゴール：ツール・知識・複数エージェントの組み方と、監視・安全・セキュリティの設定場所が分かる。

    約12時間生成AI・エージェント計画・管理

    Copilot Studio を触ったことがあるならFoundry のエージェントも「指示・ツール・知識」で組み立てる考え方は同じです。作ったエージェントを Teams や Microsoft 365 Copilot に公開するモジュールもあります。[6]

  4. 3
    3週目いまここ

    残り3分野を浅く広く回収する

    ゴール：「この要件ならこのサービス」を即答できる。細かい設定値までは追わない。

    約11時間ビジョンテキスト分析情報抽出

    時短のコツ各分野は10〜15%。モジュールの「概要」と「まとめ」を先に読み、問題を解いて分からなかったところだけ本文に戻る順番だと速く進みます。

  5. 4
    4週目いまここ

    練習問題を回して、穴だけ埋める

    ゴール：練習問題で安定して合格圏。苦手は「どの Learn ページを見ればいいか」まで分かっている。

    約10時間全分野
  6. ★
    受験日いまここ

    本番：時間配分を守って700点を取りにいく

    下の「試験当日の立ち回り」を一度読んでから臨んでください。

Python や Azure の開発経験がある人は、1・2週目と3・4週目をそれぞれ1週にまとめた2週間プランでも十分狙えます。逆に、初めて触る言葉が多いと感じたら、2週目を2週間に延ばすのが一番効果的です。

Exam day

試験当日の立ち回り

どれも公式の受験ルールに書かれている内容です。[3]

  • 約2分 / 問ペースは1問2分弱

    120分。問題数は試験ごとに変わりますが、多くの試験は40〜60問程度と公式に書かれています。

  • Learn調べるのは「調べれば確実に取れる問題」だけ

    試験中も Microsoft Learn を開けますが、時間は増えません。全部調べると時間内に終わらない設計だと公式が明言しています。

  • 休憩休憩の前に見直しを済ませる

    休憩は取れますが、時計は止まらず、休憩前に見た問題には戻れません。

  • ラボ実機操作やケーススタディが出ても慌てない

    120分は「ラボを含む可能性がある」区分の試験時間です。出るかどうかは試験開始時の説明画面で分かります。

  • 見直し迷ったら印をつけて先へ進む

    最後の見直し画面からまとめて戻れます。1問に粘りすぎないこと。

  • 24時間落ちても24時間後から再受験できる

    2回目以降は待ち時間が延びます。スコアレポートの分野別の結果を、次の作戦に使います。[2]

  • SKIP
    全モジュールの演習を全部やる

    ハンズオンは合計5本程度に絞ります。お金と時間の節約になり、理解度もほとんど変わりません。

    満点を目指す

    合格は700点。配点10〜15%の3分野は「どのサービスで何ができるか」が言えれば十分です。[1]

  • SKIP
    コードやパラメーターの丸暗記

    本番で Learn を引けます。覚えるのは「どのページに何が書いてあるか」です。[3]

    公式コース AI-103T00（4日間）が使うのは、このページの4つのラーニングパスです。自習でも同じ内容を無料で学べます。[4]

Glossary

最初につまずく用語ミニ辞典

教材を読む前に、ざっくり意味をつかんでおくと読むスピードが上がります。

Microsoft Foundry
AIアプリやエージェントを作る・試す・公開する・見張るための Azure の作業場。この試験の主役です。
Foundry Tools
文章分析（Language）、音声（Speech）、翻訳（Translator）、文書読み取りなど、用途別のAI部品の総称。
モデルLLM / SLM
文章を考える頭脳。大きくて賢い LLM と、小さくて軽い・安い SLM（小規模言語モデル）があります。
デプロイ
モデルやエージェントを、アプリから呼び出せる状態に設置すること。
RAG検索拡張生成
先に資料を検索して、その内容を根拠に答えさせる仕組み。社内文書に答えるAIの基本形です。
ベクター／ハイブリッド検索
意味の近さで探すのがベクター検索。キーワードと意味の両方で探すのがハイブリッド検索です。
エージェント
指示・ツール・知識を持ち、自分で手順を考えて動くAI。
ツール／関数呼び出し
エージェントが外部のサービスや計算を呼び出す仕組み。「AIの手足」にあたります。
MCP
AIとツールをつなぐための共通規格。USB のように、対応していれば差し替えて使えます。
マルチエージェント
役割の違う複数のエージェントが分担して仕事を進める構成。
Foundry IQ
エージェントが社内データを検索して、根拠つきで答えるための知識の土台。
Content Understanding
文書・画像・音声・動画から、必要な情報を取り出して整理するサービス。
Azure AI Search
社内データを検索できるように索引を作るサービス。RAG の土台になります。
マネージドID／キーレス
パスワードや鍵を使わず、Azure が発行する「社員証」で安全に接続する方法。
ガードレール／コンテンツフィルター
有害な入力や出力を止める安全装置。
評価・トレース
回答の正確さや安全性を点数で測るのが評価。AIが中で何をしたかを記録して後から追えるようにするのがトレースです。
