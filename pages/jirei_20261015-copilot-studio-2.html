AI活用事例Copilot Studio2026年10月15日／エネルギー（INPEX）・社内規程や法令の調べもの

AI エージェントが1,000体を超えても迷わない――INPEX が Copilot Chat と Copilot Studio を使い分けた方法

INPEX では、調べものや資料づくりに時間がかかり、産休・育休のように担当者へ聞きにくい相談もありました。

そこで Microsoft 365 Copilot を中核に据え、社内規程を調べるエージェントなどを作りました。誰でも作れる Copilot Chat と、高度な設定ができる Copilot Studio を、用途に応じて使い分けています。

導入から約1年後のアンケートでは、オフィス業務の時間が44%減ったと答えています。社内で作られたエージェントは1,000を超えました。

01こんな場面、ありませんか

「社内規程のどこに書いてあるか分からない」「法令を調べるのに半日かかった」という場面は、多くの職場にあります。産休・育休のような相談は、担当者に直接聞きにくいこともあります。

INPEX では、情報収集や調査、資料づくり、翻訳に多くの時間がかかっていました。契約書業務のように、知識の蓄積に支えられた仕事を引き継ぐ難しさもありました。さらに、AI を使うのが一部の専門家やバックオフィスに偏っていました。

02やってみたこと

Copilot Studio は、ノーコードでエージェント（役割を持つ AI アシスタント）を作るツールです。外部システムとのつなぎ込みや、自動で動かす仕組みなど、高度な設定ができます。

INPEX は、作る手段を2つに分けました。個人や非デジタル部門の人は、Copilot Chat で作る「Copilot エージェント」を使います。外部コネクタ（他のシステムとの接続）や自動の起動条件が要るものは Copilot Studio で作ります。Copilot Studio は費用とアクセス権の管理が必要なので、申請制にしました。社内規程エージェントの編集画面や、Copilot Studio の使い方を紹介する社内動画も用意されています。

  1. AI 活用推進タスクフォース「AIR」が、「AI が空気のように自然にある職場へ」という考えで活動を始めました。
  2. Microsoft 365 Copilot を2025年から本格導入し、社内規程エージェント、国内法令検索エージェント、産休・育休の問い合わせエージェントなどを社内に共有しました。
  3. 数が増えるなかで、有用なエージェントを上位のエージェントにまとめ、将来は複数をつなげて業務を自動化する方針を立てています。

※ 図の判断の言い回しは、公開記事の説明を要約して補っています。各エージェントの細かな設定は公開されていません。

03どう変わったか

これまで

調査や資料づくりに時間がかかり、聞きにくい相談は後回しになりがちでした。AI も一部の専門家しか使っていませんでした。

いま

規程や法令をエージェントに質問でき、AI の利用が現場に広がりました。社内で作られたエージェントは1,000を超えています。

導入から約1年後のアンケートでは、業務時間の削減が44%、業務の高度化が46%、エンゲージメント（仕事への意欲）の向上が43%でした。年間20億円以上の効果という試算も出ています。いずれも INPEX が公表した数字で、社内アンケートと試算に基づきます。有償ライセンスは、2025年初頭の650から1,450に増えました。

04明日から試すには

  1. 自分の部署でよく聞かれる質問（規程、手続き、よくある問い合わせ）を5つ書き出します。
  2. その答えが載っている資料（規程集など）を、読んでよい範囲で集めます。
  3. まず Copilot Chat のエージェントで、資料をもとに答える役割を試します。外部サービスとの連携が要るときだけ Copilot Studio を検討します。

準備物は、質問のリストと、答えの元になる資料です。Copilot Studio が使えるか、費用や申請のルールはどうなっているかは、社内の設定やライセンスで変わります。

05つまずきやすいところ

エージェントが増えすぎると、管理が大変になります

INPEX では、エージェントが1,000を超え、統制と柔軟性の両立が課題になっています。新しいものへの不安を持つ従業員も一定数いました。Copilot Studio を申請制にしたのは、費用とアクセス権を管理するためです。

自分の職場でも、規程の古い版を元にしていないか、AI の答えを鵜呑みにせず原文で確かめているかを、時々見直してください。人事や契約のような機密性の高い資料は、見てよい人だけが使えるように権限を確認してから渡します。

06おわりに

この事例で参考になるのは、ツールを増やすことよりも、「どの手段を、誰が、どんな条件で使うか」を先に決めた点です。規程の質問に限らず、手順書やマニュアルを使った問い合わせ対応にも応用できます。

自分の職場に置き換えると、まず「聞きにくい・探しにくい質問」を1つ選び、その答えが載っている資料を使った小さなエージェントを作るところから始められます。
