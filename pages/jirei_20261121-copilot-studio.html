AI活用事例Copilot Studio2026年11月21日／化学メーカー（Dow）・物流の請求書チェック

運賃請求書の誤りを、数日がかりから数秒で見つけられるようになりました

米国の化学メーカー Dow では、物流チームが年10万件の PDF 請求書を手作業で確かめており、料金の誤りを見落とすおそれがありました。

そこで Copilot Studio で、請求書を読み取って契約条件と照らし合わせるエージェントと、結果を言葉で調べられるエージェントの2つを作りました。

試験運用を始めて数週間で、これまで数日〜数週間かかっていた過大請求や誤りを、数秒で見つけられるようになったと紹介されています。

01こんな場面、ありませんか

取引先から届く請求書の形式がばらばらで、1枚ずつ開いて契約の単価と見比べている。件数が多すぎて全部は確かめきれず、細かな上乗せ料金は「たぶん合っているだろう」と通してしまう。経理や購買、物流の担当者なら、思い当たる場面があるのではないでしょうか。

Dow は、1日に最大4,000件の出荷を、トラックや船などあらゆる輸送手段で手配しています。物流チームは、料金の誤りや過払いにつながるミスがないか、請求書を手作業で確かめていました。ただ、PDF の請求書だけで年10万件あり、中には20ページに及ぶものもあります。量も形式も多すぎて、効率よく監査（中身のチェック）ができない状態でした。

02やってみたこと

使ったのは Copilot Studio（プログラムをほとんど書かずに、AI エージェントを作れる Microsoft のツール）です。Dow はまず Microsoft と合同のワークショップを開き、エージェントが役立つ業務を洗い出しました。そのうえで、ばらつきの少ない「北米のトラック輸送」の請求書だけに範囲をしぼって始めています。

作ったエージェントは2つです。1つ目は、人が指示しなくても裏で動き続ける「自律型」のエージェントです。2つ目は、社員が質問すると答える「Freight Agent（運賃エージェント）」で、社内のデータ基盤「Integrated Data Hub」にある4万3,000件の請求書をもとに答えます。開発には物流チームの専門家も加わりました。

  1. 自律型のエージェントが、受信メールを見張り、添付された PDF の請求書を見つけます。
  2. 請求書の中身を読み取り、分析しやすい形のデータに整えます。
  3. 運賃・計上済みの費用・請求額が、取り決めた契約条件と合っているかを確かめます。
  4. 食い違い、条件に合わない請求、金額の誤りを色分けし、ダッシュボード（数字を一覧できる画面）に出します。
  5. 社員は Freight Agent にふだんの言葉で質問し、運送会社・トラック・製品の種類ごとに比べて原因を調べます。

※ 手順の順番は記事の記述をもとに整理したものです。Copilot Studio での具体的な設定内容は公開されていません。

03どう変わったか

これまで

年10万件の PDF 請求書を人が確かめていました。過大請求や誤りを見つけるのに、数日から数週間かかることもありました。

いま

エージェントが誤りの候補を数秒で示します。二重の請求や、荷下ろしの遅れで上がった料金なども追えるようになりました。

試験運用を始めて数週間で、社員とエージェントが一緒に、数千件の請求書から異常を見つけ、節約できそうな金額を示せるようになったと、Microsoft のブログで紹介されています。全世界のあらゆる輸送手段に広げれば、運賃を数百万ドル規模で節約できる見込みだとしています。ただし、これは見込みの数字で、実際に節約できた金額は公表されていません。担当の責任者は「年間の運賃は数十億ドルを超える。エージェントが過大請求を見つけ、チームはより価値の高い仕事に集中できる」と話しています（意訳）。

04明日から試すには

  1. 毎月たくさん届き、決まった条件と見比べている書類（請求書、見積書、経費の申請など）を1つ選びます。
  2. 範囲を小さくしぼります。Dow のように「この取引先の、この種類の書類だけ」から始めると、効果を確かめやすくなります。
  3. 照らし合わせる元の条件（契約の単価表など）を整理し、Copilot Studio のエージェントに「何と何を比べ、どこが違えば知らせるか」を決めて試します。

準備物は、見比べる書類のサンプルと、正しい条件が書かれた資料、そして業務に詳しい担当者です。メールを見張って自動で動かす仕組みや、社内のデータ基盤につなぐことができるかは、ライセンスや社内の設定で変わります。まず IT 部門に確認してください。

05つまずきやすいところ

先にデータを整え、範囲をしぼる

Dow は、エージェントを作る前から社内のデータ基盤を整え、社員がデータや AI を扱えるようにする研修も進めていました。記事は、Copilot を組織のデータにしっかり結びつけることを、うまく進めるための要点として挙げています。最初の対象をばらつきの少ない北米のトラック輸送にしぼったことも、早く効果を示せた理由とされています。

社内で真似するときは、AI が示した「誤りの候補」をそのまま支払い停止などに使わず、最後は人が確かめる流れにしてください。記事も、時間のかかる作業はエージェントに任せつつ、大事な判断には人が関わり続ける設計をすすめています。AI はもっともらしい間違い（ハルシネーション）をすることもあります。請求書や契約書には取引先の情報が含まれるので、誰がエージェントの結果を見られるかも先に決めておきましょう。

06おわりに

この事例のポイントは、人が「全部は見きれない」とあきらめていた照合作業を、エージェントに先にやってもらい、人は気になるところだけを調べる形に変えたことです。決まったルールと見比べる仕事は、請求書に限らず、経費精算や発注書、検査記録など多くの業務にあります。Dow もすでに物流と業務運営で100を超える使い道を洗い出し、研究開発の特許づくりを助けるエージェントなども作り始めています。

自分の職場に置き換えると、たとえば「経費の申請が社内規程に合っているか」「見積書の単価が契約どおりか」といった確認作業が当てはまります。まずは件数が多く、ルールがはっきりしている書類1種類から始めると、効果が見えやすいでしょう。
