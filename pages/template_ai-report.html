09

このテンプレートの使い方

差し替え箇所は1か所にまとめてあります。数値を書き換えれば、グラフ・表・凡例はすべて自動で追従します。

編集の手順

  1. ソース内の const DATA = { ... } を探します。ページに出る数字・ラベル・出典はすべてここにあります。
  2. 数値を自分のデータに置き換えます。配列の長さを変えても（月を12件にする、部門を追加するなど）グラフ側が自動で合わせます。
  3. 色を変えたいときは先頭の :root にある --s1〜--s8 を書き換えます。ダークモード用の値も同じ名前で下にあるので、2か所セットで変更してください。
  4. 不要な章は <section class="sec" id="s6"> ごと削除すればOKです。ナビの該当リンクも一緒に消してください。
  5. PDFにするときは右上の「印刷 / PDF」から。章と図は改ページで切れないようにしてあります。
