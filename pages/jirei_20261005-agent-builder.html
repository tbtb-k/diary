AI活用事例Agent Builder2026年10月5日／IT・ソフトウェア（Microsoft 社内）・社内の情報検索と文書作成

決まった資料だけを読ませる小さな検索エージェントを、Microsoft の社員が数分で作っています

Microsoft 社内では、社員が自分の部署の資料やデータを AI から使えるようにしたい一方で、安全性とルールも守る必要がありました。

そこで、社員が Agent Builder（旧称：Copilot Studio agent builder。質問に答えるエージェントを数ステップで作れるツール）で、読ませる資料を絞った「検索エージェント」を作れるようにしました。

広報チームの文章の下書きや、顧客情報の確認などに使われています。削減時間などの数字は公表されていません。

01こんな場面、ありませんか

文章を書き始める前に、方針の資料や過去の計画書を何冊も開いて確認する。顧客の状況を知りたくて、複数の画面を行き来する。どの職場にもある場面です。

Microsoft 社内の社員も、Microsoft 365 Copilot（業務アプリに組み込まれた AI アシスタント）を、自分たちの組織にしかないデータにも使いたいと考えていました。ただし、情報の扱いは安全でなければなりません。

02やってみたこと

Agent Builder は、Copilot Chat（Teams などから使える会話型 AI）の中で、テンプレートを選ぶか数項目を入力するだけでエージェントを作れるツールです。出典では、数分で動かせると紹介されています。

作られた例は、広報チームのブログ下書き用「Security Comms Agent」、顧客のプロファイルをまとめる「Know Your Customer」、使えるプロンプト（AI への指示文）を探せる「Prompt Buddy Agent」などです。

  1. Copilot Chat で Agent Builder を開き、テンプレートを選ぶか、いくつかの欄に入力します。
  2. エージェントの役割（指示）と、参照させるデータの置き場所を決めます。広報チームの例では、事業目標や文体のガイドライン、広報計画などの社内資料と、Microsoft の公開の学習サイトを読ませています。
  3. できあがったエージェントに質問すると、その資料にもとづいた回答や、方針に沿った下書きが返ってきます。

※ 手順の細かい画面操作は、Agent Builder の一般的な作り方で補っています。各エージェントの実際の指示文は公開されていません。

03どう変わったか

これまで

組織固有の資料やデータを AI から使いにくく、担当者が資料を探して読み、文章を一から作っていました（出典の説明にもとづく整理です）。

いま

読ませる資料を絞った小さなエージェントを、現場の社員が数分で作れます。広報チームは方針に沿った下書きを会話で得られます。

効果を示す具体的な数字は、出典では公表されていません。公表されているのは、5つのエージェントの用途と、作り方、導入時の注意点です。

04明日から試すには

  1. 毎回同じ資料を見て答えている業務を1つ選びます。たとえば、規程の問い合わせ対応や、定型の文書の下書きです。
  2. 使ってよい資料を3〜5点に絞り、置き場所を決めます。Agent Builder で、その資料だけを読むエージェントを作ります。
  3. 同じ部署の数人で使い、答えが合っているかを確かめます。うまくいけば、少しずつ範囲を広げます。

必要なもの：Microsoft 365 Copilot の利用環境と、読ませてよい資料です。Agent Builder が使えるかどうかは、会社のライセンスや管理者の設定で変わります。

05つまずきやすいところ

最初に、安全の担当部署と相談します

出典は、セキュリティ・法務・コンプライアンス・IT の担当と早めに連携すること、読ませるデータの品質や権限を整えること、小さなグループから始めて段階的に広げることを挙げています。Microsoft 社内では、エージェントが読めるデータを自社の範囲に限っています。

社内で真似するときも、機密情報や個人情報を読ませてよいかを先に決めましょう。AI の回答は間違うことがあるので、重要な内容は元の資料で確認してください。

06おわりに

この事例のポイントは、大きな仕組みを作らなくても、「この資料だけを読む小さなエージェント」で日々の確認作業を減らせることです。うまくいった小さなエージェントが、次の大きな活用への足がかりになります。

自分の職場に置き換えると、新人向けのマニュアルや社内規程を読ませた質問用エージェントなら、試しやすそうです。まずは自分の部署の中だけで使い、答えの正確さを確かめてみてください。
