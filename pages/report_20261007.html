2026/09/30展開中MC1483844

GPT-6.1 SolとClaude Sonnet 5.5が、M365 Copilotで選べるように

何があった？
OpenAIのGPT-6.1 SolとAnthropicのClaude Sonnet 5.5が、Copilotのモデル選択に加わりました。CoworkとCopilot Studioでは9/30から展開が始まり（従量課金の設定が必要）、Word・Excel・PowerPoint・チャットではM365 Copilotライセンスの利用者向けに、翌週から段階的に広がります。
嬉しい・注意点
管理者の操作は基本的に不要ですが、Claudeを使うにはAnthropic、GPTを使うにはOpenAIを「サブプロセッサー（データ処理の委託先）」として許可する設定が前提です。新モデルには利用量の上限があり、上限に達したら「自動」や別のモデルに切り替えれば作業を続けられます。
支援現場でのひとこと
「新しいモデルが出てこない」と聞かれたら、まず管理者側でAnthropicやOpenAIの許可設定がどうなっているかを確認するのが近道です。

出典：Microsoft 365 Message Center Archive「MC1483844」

2026/09/30GA

SharePoint・OneDriveのCopilotが一般提供に。一部の機能は従量課金

何があった？
SharePointとOneDriveのCopilotが一般提供になりました。OneDriveのCopilotはSharePointと同じ基盤で作り直されています。料金は「Copilotライセンス＋従量課金」の組み合わせで、画像の生成・編集、サイトの利用状況レポート、列の自動入力などはクレジットを使う機能です。10/3には、これらの支出も管理センターの「コスト管理」の方針で制御できるようになったと報じられました。
嬉しい・注意点
SharePointのエージェントは、まだコスト管理の対象外です。また、PowerShellでCopilotを使えるサイトを絞る設定は11/1で廃止され、以後は「サイトのAI設定」や制限付きコンテンツ検出（Restricted Content Discovery）で管理します。
支援現場でのひとこと
PowerShellでサイトを絞っている組織は、11/1までに新しい管理方法へ移す必要があります。情報システム部門への早めの声かけが安心です。

出典：Topedia Blog（GA）／Topedia Blog（コスト管理）／Topedia Blog（PowerShell設定の廃止）

2026/09/30展開中MC1484008

「プラグインレジストリ」登場。エージェントやスキルの入口が「プラグイン」に一本化

何があった？
組織で認めたエージェント、スキル、コネクタ、MCPサーバーを「プラグイン」としてひとまとめに登録・管理する仕組みです。画面では「エージェント」「エージェントとスキル」「カスタマイズ」のボタンが「プラグイン」ボタンに置きかわります。レジストリは9月下旬〜10月下旬、画面の変更は10月下旬〜11月下旬に展開予定です。
嬉しい・注意点
管理者はM365管理センターとAgent 365の「ツール」から一括で管理できます。設定作業は不要ですが、ボタンの名前が変わるので、社内マニュアルや研修資料の更新が必要になります。
支援現場でのひとこと
画面キャプチャを使った手順書は、11月にかけて見た目が変わる前提で作ると手戻りが減ります。

出典：Microsoft 365 Message Center Archive「MC1484008」／Microsoft Tech Community

2026/10/06リリースノートRM512429

10/6のリリースノート：検索からチャットへ、答えの出し直し、PowerPointの自作スキル

何があった？
Copilot Searchの検索結果から、そのままチャットで追加の質問や資料づくりができるようになりました。Copilot Chat（Web）では、答えの最後のメニューから「もう一度」や「モデルを切り替え」で別の答えを出し直せます。ほかに、PowerPoint（Windows）での自作スキル、Mac版PowerPointでのSharePoint・OneDriveのファイル名による参照、Copilot AnalyticsでのCoworkの利用状況の可視化も加わりました。
嬉しい・注意点
管理者向けには、Copilotコネクタ（外部データをCopilotにつなぐ仕組み）の設定を、サポートに問い合わせず管理センターで直せるようになりました。
支援現場でのひとこと
「答えがいまいちなら、モデルを切り替えて出し直す」は、モデルの違いを体験してもらう勉強会のミニ演習にちょうどいい機能です。

出典：Microsoft Learn「Release Notes for Microsoft 365 Copilot」

2026/09/30開発中RM570432

Copilot Studio、エージェントが自分の実行結果から改善点を提案する「セルフラーニング」

何があった？
Microsoft 365ロードマップに追加された項目です。エージェントが完了した実行を振り返り、毎回同じ順番で呼んでいるツールの組み合わせを見つけて「ワークフローにまとめませんか」と作成者に提案します。根拠と見込まれる効果も一緒に示されます。プレビューは9月、一般提供は10月が目標です。
嬉しい・注意点
決まった手順をワークフローに置きかえると、毎回AIに考えさせる量が減り、クレジットの節約につながります。採用するかどうかは作成者が決める仕組みです。
支援現場でのひとこと
「動かしながら育てる」という考え方は、エージェントを作った後の運用の話をするときの良い材料になります。

出典：Microsoft 365 Message Center Archive「RM570432」

2026/10/01学習リソース

Copilot Studioの学び方を4段階で整理。10/8にスキルアップのWebセミナー

何があった？
Copilot Studioのブログで、学び方が「知る→手を動かす→資格→学び続ける」の4段階にまとめられました。10/8の新機能紹介Webセミナー、無料のハンズオン教材「Agent Academy」、公式コース（PL-7008など）と認定資格、AI Skills Navigatorの学習リストが紹介されています。

支援現場でのひとこと
勉強会の「次の一歩」として、受講者のレベル別に案内先を決めておくと、終わった後の自習につなげやすくなります。

GitHub Copilotが、デスクトップアプリを画面操作できるように

何があった？
GitHub CopilotのアプリとCLI（コマンドで操作する画面）で、Windows・Macのアプリをクリックや入力で操作する「コンピューター操作」がプレビューになりました。APIのない古いソフトや、画面操作しかできないアプリの作業を自動化できます。

今週のかみ砕き用語

プラグイン（Plugins）

今週の「プラグインレジストリ」で、Copilotの画面のボタン名にもなります

ひとことで

Copilotに後から足せる「追加の力」をまとめて呼ぶ名前です。エージェント、スキル、コネクタ、MCPサーバーが含まれます。

たとえるなら

スマホのアプリストアの「会社公認アプリ」コーナー。会社が認めたものだけが並んでいて、社員はそこから必要なものを選んで使います。

押さえておきたいこと

  • これまで「エージェント」「カスタマイズ」などに分かれていた入口が、「プラグイン」ボタンに統一されていきます（10月下旬〜11月下旬）。
  • どのプラグインを使わせるかは、管理者がM365管理センターやAgent 365で決めます。
  • Copilot Studioで作ったエージェントも、利用者から見ればプラグインのひとつとして並ぶイメージです。
勉強会での言い方：「Copilotに機能を足したいときは『プラグイン』ボタンを見てください。会社が認めたものがそこに並びます。」
