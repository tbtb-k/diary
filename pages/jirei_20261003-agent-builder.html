AI活用事例Agent Builder2026年10月3日／公務（人事院）・人事／情報セキュリティ

管理職の「部下への声かけ」練習から規程の調べものまで、人事院はコストを抑えて3つのエージェントを自分たちで作りました

人事院（職員約600名）では、部下へのフィードバックの機会が少ないことや、職員の業務量の多さが課題でした。

そこで Microsoft 365 Copilot の Agent Builder（文章で指示して自分用の AI アシスタントを作る機能）を使い、コーチング練習用など3つのエージェントを職員自らが作りました。

数字で公表されているのは有料版 Copilot の検証アンケートで、「有料であっても使いたい」が8割超でした。エージェントそのものの削減効果は公表されていません。

01こんな場面、ありませんか

部下に伝えにくいことを、どう切り出せばよいか。管理職なら一度は悩んだことがあるはずです。しかも、練習できる場はなかなかありません。

不審なメールが届いたとき、詳しい人に聞かないと判断できない。何百ページもある規程のどこを見ればよいか分からない。そんな場面も、多くの職場にあるのではないでしょうか。

人事院では、国家公務員志望者の減少、若手職員の離職の増加、長時間労働、部下へのフィードバック機会の不足などが課題でした。事務総局の担当者は「職員の業務量は依然として多い状況」と述べています（意訳）。

02やってみたこと

Agent Builder は、Microsoft 365 Copilot の中で、AI に役割と参考資料を文章で教えて「専用エージェント」を作る機能です。プログラミングは要りません。

人事院は、民間のサービスや Copilot Studio（より本格的にエージェントを作るツール）も検討しました。そのうえで「なるべくコストがかからず、多くの人が使える」ことを重視し、Agent Builder を選んで内製しました。作ったのは次の3つです。

コーチング支援エージェント：部下の属性を入力して仮想の部下を設定し、さまざまな場面でフィードバックの練習をします。会話への AI のアドバイスや、マネジメント傾向の自己診断もできます。

不審メール判定エージェント：メールが不審かどうかの判定から、種類の分類、職員への返信案づくりまでを行います。

情報セキュリティ関係規程のナビ：数百ページの規程を参考資料として登録し、条文を引用しながら回答案を出します。

  1. 管理職のフィードバック練習、不審メールの判定、規程の調べものという、悩みの多い業務を選びます。
  2. Agent Builder で、役割や参考資料（規程など）を指定してエージェントを作ります。
  3. 職員が日常の業務で使い、コーチング練習の相談や、規程に沿った回答案づくりに役立てます。

※ 出典に書かれているのは、作ったエージェントの機能と、Agent Builder を選んだ理由です。細かい設定内容や指示文は公開されていません。上の手順は、その機能の説明をもとにまとめています。

03どう変わったか

これまで

部下へのフィードバックを練習する機会が少なく、不審メールの判定や規程の調べものは、経験の豊富な職員に偏りがちでした。

いま

仮想の部下で練習でき、不審メールの判定と返信案づくりも手伝ってもらえます。規程は、条文を引用した回答案が出てきます。経験の差に左右されにくくなりました。

公表されている数字は、有料版の Microsoft 365 Copilot を試した結果です。2025年4月に16名で始め、同年6月に178名へ広げ、9月に本格利用に入りました。アンケートでは「有料であっても使いたい」が8割超、「業務上必要と思う」は5段階で平均4.24でした。いずれも人事院が公表した数字です。

一方で、同じアンケートで約7割が「AI エージェントは未使用」と答えており、人事院は活用の推進を続けるとしています。個々のエージェントによる時間の削減などは公表されていません。

04明日から試すには

  1. 身近な「悩みの多い業務」を1つ選びます。例：新任者からの同じ質問、規程の調べもの、練習したい会話。
  2. 参考にする資料（規程集、よくある質問の一覧など）を用意し、Agent Builder に「誰向けに、何をして、何は答えないか」を文章で伝えます。
  3. まず数人で試し、回答の間違いや抜けを直してから、少しずつ広げます。

必要なもの：Microsoft 365 Copilot を使える環境と、参考にする資料です。Agent Builder が使えるかどうかは、ライセンスや管理者の設定で変わります。まず情報システム部門に確認してください。

05つまずきやすいところ

入力してよい情報を決めておきましょう

人事院は、導入の初期には入力できる情報を「機密性1情報」（公表済み、または公表できる情報）に限りました。2025年10月に、機密性2の情報の入力を解禁しています。段階的に進め、職員の AI リテラシーの向上を重視したとのことです。

また、検証の担当者は「どの業務で効果が出るのかを手探りで検証する必要があった」と述べています（意訳）。AI の答えには間違いが混じることがあります。規程の回答案も、最後は必ず人が条文で確かめましょう。

06おわりに

人事院の事例は、「高い道具をそろえる」より先に「コストを抑え、多くの人が使える形で作る」を選んだ点が参考になります。練習・判定・調べものという、3つの違う業務を同じ道具で作っていることにも注目です。

自分の職場に置き換えると、面談の練習相手、問い合わせメールの仕分け、社内規程の案内係のうち、どれか1つなら今月中に試せそうです。まずは数人で使い、役立つかを確かめてみてください。
