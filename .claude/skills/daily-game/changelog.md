# ほしくずサバイバー：毎日の記録

新しい日を上に足していきます。テストの数字は、前の日と比べるために必ず残します。

書き方：

```
## Day N — YYYY-MM-DD（曜日）<短い題名>
- テーマ：<曜日のテーマ／感想 #番号／テストのNG対応>
- 変えたこと：<遊ぶ人目線で1〜3行>
- テスト：<OK数/全体>。何もしない 平均◯秒／自動操作 平均◯秒・クリア◯/4／ファイル◯KB
- 感想への対応：<#番号と内容。なければ「なし」>
- 気づいたこと：<次の日以降の自分へのメモ。ネタ帳に足したものなど>
```

日曜日は、その下に「### 週報」として、今週の変化のまとめと、来週の方向の提案を3つ書きます。
